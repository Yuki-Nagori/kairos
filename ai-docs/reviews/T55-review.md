## 口径（方案 A：core 简化启发式）

- **候选限表面单元**：浇口落在制品表面，内部单元不可能是浇口位置。表面单元由
  `surface_faces` 的顶点集合判定（含其一顶点即视为表层），成本 O(面数 + 单元数)。
  这是与「体心搜索」相比的关键修正——否则 Top-N 会给出体内部的点，无法落成浇口。
- **评分 = 流动长度均衡 × 壁厚可达性**：
  - 均衡项 `1 - 最长流动距离 / 包围盒对角线`（最长流动距离 = 到最远单元形心的距离）；
  - 壁厚项按单元最短高 `det / (2·A_max)` 相对全场中位数打折，下限 0.5（薄壁冻死风险）；
  - 立方体上最佳候选落在某个面的中心（两轴居中、一轴贴面），与直觉一致。
- **适合度场**：每个单元取「最近候选」的分值，逐单元与云图/探针同域，直接作为当前场
  载入视口（场名「浇口适合度」）。
- **不承诺与商业软件数值一致**：面板明确标注「启发式建议，非求解结果」；无纤维 /
  多型腔 / 工艺前置（对齐「无浇口即可跑」的行为）。

## 处理记录

- **立即修**：初版「壁厚」用单元最短高，在均匀体素网格上是常数（两次评分无差别）；
  改为候选限表面 + 厚度相对中位数折减后，薄壁件才真正被扣分。测试从「跨几何比大小」
  （不成立）改为「厚度折减函数单测 + 表面性断言」。
- **消融抽查**：临时把「候选限表面」去掉（候选池改回全单元）→
  `candidates_are_limited_to_surface_cells` 与 `best_candidate_sits_near_the_centre_of_a_box`
  双双变红（2 failed / 5 passed）；文件级还原后复绿（7 passed）。
- **回流任务**：无新增。
- **接受并记录**：适合度场经 JSON 传输（5 万单元 ≈ 1 MB）；若后续网格规模上一个量级，
  再走 T51 的二进制通道（当前实测 62.5 万单元场 ≈ 12 MB，属「可选优化」而非阻塞）。
