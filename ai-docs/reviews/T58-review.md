## 交互与口径

- **回填终点**：浇口的型腔端是 case 侧 `GatePortal` 取用的端点，所以拾取写**终点**，
  起点保持表单值（用户可先填起点或拾取后微调）。面板文案明确写出这一点。
- **吸附口径**：优先命中三角形的最近顶点（表面网格顶点即制品网格节点）；顶点坐标
  不可用（索引越界 / 无节点数据）时回退**命中单元中心**（该单元所有表面顶点均值），
  两者都取不到才用命中点本身。单元索引经 `faceCells` 与云图同域。
- **模式判定顺序**：无活跃方案 → 「请先创建或选择一个方案」；有方案但视口未载入网格 →
  「请在视口载入网格后再拾取放置」。视口网格失效（重新导入 / 生成中）时 store 复位标志
  并退出放置模式，避免点击落空。
- **连续放置**为按钮式开关（不是复选框）：塞进流道/浇口表单行时不挤动既有输入的
  DOM 次序，面板测试沿用位置选择器仍然稳定。
