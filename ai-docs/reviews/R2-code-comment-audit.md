**门禁固化**（本轮新增）：`scripts/comment-style.mts` + `bun run lint:comments`

`exit 1` 报出该行，还原后通过。文档（`ai-docs/`）是规划信息的正确去处，
不在扫描范围。

补充扫描（规范未明确覆盖、按同一精神处理）：代码里另有 2 处**里程碑编号**
