## 本轮做了什么（第一步）

- **张量场读取**：`volSymmTensorField` 从「明确不支持」升级为独立类型——6 分量
  （OpenFOAM 顺序 xx, xy, xz, yy, yz, zz）、模量 `sqrt(xx²+yy²+zz²+2(xy²+xz²+yz²))`（与
  OpenFOAM `mag(symmTensor)` 同口径）、主方向（3×3 Jacobi 对角化取 |λ| 最大特征向量，
  **符号规范化**为绝对值最大的分量为正，保证同一场多次读取方向一致）。
- **两条消费路径**：标量入口（`read_field`）取模量，直接把饱和应力云图送上视口；
  张量入口（`read_tensor_field` / `load_tensor_field`）给出分量 + 模量 + 主轴，
  结果面板展示 `|σ|` 范围与首单元主方向。
- 非对称张量（`volTensorField`，如 `gradU`）仍明确拒绝，错误文案列出支持的三种场类型。

## 未做的部分（明确记录）

- **`filler` 写进 case 材料字典**：T86/T91 都写明「关键字待与上游冻结」。在没有上游
  确认的字典名之前往 `moldingDict` 里塞自定义键，会让求解器直接报未知关键字——风险大于
  收益。等上游给出填料字典口径（或明确不需要）后再做；届时改动很小（一个 dict writer + 契约测试）。
- **取向张量 `a2` 的求解与结果消费**：等上游取向求解进 release bundle（T91 开工条件）。
- **主轴的方向可视化**（箭头 / 椭球叠加层）：依赖取向场真实数据做验收，与上一条一起做。
