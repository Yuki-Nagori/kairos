## 定义与依据

- 纵横比 = 最长棱 ÷ 最短高（Moldflow Aspect Ratio 口径）。四面体最短高由最大面面积给出：
  `h_min = 3V / A_max = det / (2·A_max)`，故 `aspect = 2·L_max·A_max / det`。
  角点四面体解析值 √6 ≈ 2.449，正四面体 √6/2 ≈ 1.225（测试锁定）。
- 退化单元（`det → 0`）分母取下限 1e-15，返回大有限值而非无穷：IPC 数值字段与
  serde_json 都不接受非有限数（会序列化成 null 破坏前端契约）。
- 双域匹配率 = `paired / (paired + unpaired)`，空网格归零（与 thickness 统计的空场口径一致）。
