## 口径与取舍

- **覆盖 = 图连通**：单元形心 + 共享面邻接，从浇口命中单元做多源 Dijkstra（边权 =
  形心距离）。不可达单元即「熔体走不到」的区域——这是硬物理约束，比阈值打分更可辩护。
- **到达序场**：归一化最短路径长度（0 = 浇口、1 = 最远可达），直接作为当前场进视口云图；
  未覆盖单元固定为 1.0，必须结合 `uncoveredCells` 判读（面板给计数与占比）。
- **不做冻层/流动长度比判据**：体素网格的单元最短高在均匀网格上是常数（T55 已记录过
  同一问题），用「流动长度 / 壁厚」阈值会得出与网格尺寸无关的假结论。等值域壁厚
  探测进 core 之后再考虑加这一层。
- **落点告警**：浇口到最近单元形心超过平均单元尺寸 5 倍时提示核对坐标（填错坐标时
  用户会看到「全件不可充填」，这条告警把根因点出来）。

## 处理记录

- **立即修**：`preview` 的距离数组用 `f64::INFINITY` 表示不可达；场映射里显式判
  `is_finite()`，避免 NaN 传播到云图（JSON 无法承载非有限数）。
- **消融抽查**：把多源种子从「全部浇口单元」改成「仅第一个浇口」→
  `multiple_gates_share_the_source_set` 变红（两处 0 不再同时成立）；文件级还原后复绿。
- **回流任务**：无新增。
- **接受并记录**：覆盖场与到达序经 JSON 传输（62.5 万单元 ≈ 12 MB）；与 T55 同一
  条记录——若网格规模再上一个量级，统一改走二进制通道。
