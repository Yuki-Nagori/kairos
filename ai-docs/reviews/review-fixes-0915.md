## 边界与后续优化

- 本机验证为 macOS，真实子进程测试使用 bash；本轮未完成 Windows/WSL 与 Linux 的整机求解验收，也未重新部署 VM 求解器。跨平台停止命令仍需在对应平台发布门禁中实测。
- 远程连接连续失败或停止无法确认时，作业明确失败并提示检查 VM，不宣称求解已经终止。
- 8 核是当前静态调度预算，动态读取 VM 核数属于后续能力；超额请求现在直接报错，不再永久排队。
- 文件缓存使用 mtime/长度及显式重扫失效；外部程序若同时伪造相同时间与长度，需重扫目录以强制刷新。
- 二进制传输与共享快照减少 JSON 和重复提取；本轮没有测量 GUI 帧延迟或发布包性能增益，不报告未实测加速比。
- 原评审中进一步提出的运行生命周期服务抽取、CSV/张量统计下沉、其余 DTO 收口、物理功能路线图与文档状态治理是持续优化方向，不能由本轮 12 项缺陷修复等同为已完成。
