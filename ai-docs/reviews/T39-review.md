## 决策结论

1. **自研 WebGPU 主路径继续**（已采纳方向不变）：POC 证明同一 RenderMesh
   数据模型可在 WebGPU 上以等价语义渲染（云图 / 剖切 / 线段叠加），自研
   成本可控，VTK.js 对照 POC 取消——其「降低实现成本」的前提已被自研
   后端满足，且 VTK.js 的预览级 WebGPU 路径不满足三端主后端承诺。
2. **WebGPU 不可用时回退 WebGL2**（保持硬件 GPU 前提，无 CPU 渲染）。
3. **三端真机验收与 FPS 实测**是决策门剩余的唯一未闭环项，处理方式：
   在三平台真机执行 `utils/bench/webgpu-render.ts` + 真机走查（旋转 /
   云图 / 剖切 / 拾取），数字回填本报告后关闭决策门。
