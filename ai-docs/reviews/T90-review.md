## 修正口径（对照 T86 可行性结论）

- **有效密度下降 x%** → 比容 ×`1/(1-x)`：缩放 Tait 的 `b1m` / `b1s`。
  `b2*`（温度项）、`b3`（压力项）、`b4*`、`b5` 量纲上不随密度缩放，保持原值。
- **表观黏度下降 y%** → 缩放 Cross-WLF 的 `D1`（零剪切黏度前因子，与 η 成正比）；
  `n` / `τ*` / `A1` / `A2` 不动（形状参数，不随发泡剂含量变）。
- **只改 case，不改工程**：修正后的材料是本 case 的局部副本，工程文件里的材料保持原值，
  用户可以做「发泡 / 不发泡」两套 case 对比。
- **告警进报告**：`CaseReport.warnings` 带「微发泡近似（N₂ 质量分数 2.0%）：有效密度 −20.0%、
  表观黏度 −30.0%——经验修正，非预测级。」——CLI JSON 与工艺面板（T72 的通路）自动展示。
- **面板标注**：材料面板用琥珀色标题写明「非预测级：只做有效密度与表观黏度修正」。
