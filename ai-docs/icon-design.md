# Kairos 图标设计规范

适用范围：`src-web/components/ui/icons/` 下全部图标组件。本文件定义图标的
设计语言、双轨分类与强制参数，保证所有图标风格一致、比例统一。新图标落地前
先读本文；新增条目须在「图标清单」登记。

## 设计语言：超现代（Hyper-modern）

- **几何化**：只用直线、折线、矩形、圆与圆角矩形，不用手绘曲线与装饰细节；
- **大圆角**：外形轮廓统一 `rx=2.5`（24 网格），端点 `stroke-linecap="round"`、
  拐角 `stroke-linejoin="round"`，无尖锐棱角；
- **均匀描边**：全部线条同一粗细（`stroke-width="2"`），不使用粗细对比；
- **负空间**：元素之间至少保留 2 个网格单位的间隙，贴边即返工；
- **克制**：一个图标只表达一个概念，能省的细节全部省掉。

## 双轨分类

### 一、单色线性图标（Mono）——按钮 / 工具栏 / 状态

| 参数        | 强制值                                                           |
| ----------- | ---------------------------------------------------------------- |
| viewBox     | `0 0 24 24`（画布恒为正方形）                                    |
| 视觉主体    | 安全区 `3.5–20.5`（17×17），**整体轮廓呈正方形**，不得压扁或拉长 |
| 描边        | `stroke="currentColor"`、`stroke-width="2"`、`fill="none"`       |
| 圆角 / 端点 | `rx="2.5"`、`stroke-linecap="round"`、`stroke-linejoin="round"`  |
| 可访问性    | `aria-hidden="true"`（装饰性，语义由按钮文字承担）               |

- 颜色只有 `currentColor` 一种，跟随主题；组件内**不出现任何硬编码色值**；
- 宽度类由调用方传入（`class="h-4 w-4"`），组件自身不写尺寸。

参考实现（`ShellIcon.vue`，终端窗口：圆角方窗 + 标题栏分隔线 + 提示符 + 光标）：

```html
<svg
  viewBox="0 0 24 24"
  fill="none"
  stroke="currentColor"
  stroke-width="2"
  stroke-linecap="round"
  stroke-linejoin="round"
  aria-hidden="true"
  class="inline-block"
>
  <rect x="3.5" y="3.5" width="17" height="17" rx="2.5" />
  <path d="M3.5 8.5h17" />
  <path d="M8.5 12.5l2.5 2-2.5 2" />
  <path d="M13 16.5h2.5" />
</svg>
```

### 二、彩色图示图标（Art）——复杂功能说明 / 空态引导

用于按钮装不下的「解释性」场景：功能说明卡、空态引导、onboarding 图示。

| 参数     | 强制值                                                                           |
| -------- | -------------------------------------------------------------------------------- |
| 网格     | 同 24 网格，与 Mono 图标同形（先画 Mono 骨架，再上色）                           |
| 配色     | ≤ 3 色：emerald `#10b981`（主）、amber `#f59e0b`（强调）、zinc `#71717a`（中性） |
| 层次     | duotone 手法：结构线用实色描边（同 Mono），块面用 10%–20% 透明度同色填充         |
| 命名     | `XxxArt.vue`（与 Mono 的 `XxxIcon.vue` 区分）                                    |
| 用途注记 | 文件头注明适用场景（如「空态：尚未导入几何」）                                   |

- 彩色图标**只用于说明，不用于操作按钮**——操作入口一律 Mono，保证按钮
  视觉重量一致；
- 主题适配：结构描边优先 `currentColor`，装饰面色值可固定（深浅主题下均需
  目视核对对比度）。

## 流程与登记

1. 新图标先在下方「图标清单」登记（名称 / 分类 / 用途），再写组件；
2. 复用优先：已有图标能表达的概念不新画（换概念才换图标）；
3. 每个图标一个 SFC，文件头一行说明概念与网格约束；
4. 落地后跑 `bun run verify`，并按本文件「审查清单」自查。

## 图标清单

| 组件        | 分类 | 用途                             |
| ----------- | ---- | -------------------------------- |
| `ShellIcon` | Mono | 虚拟机 / Shell 环境入口          |
| `XxxArt`    | Art  | （暂无——首个彩色图示落地时登记） |

## 审查清单

- [ ] viewBox 与视觉主体是否为正方形（17×17 安全区）？
- [ ] 描边粗细、圆角、端点是否与全组一致？
- [ ] 元素间隙 ≥ 2 网格单位，无贴边？
- [ ] Mono 是否纯 `currentColor`、无硬编码色值？
- [ ] Art 是否 ≤ 3 色、duotone 层次、只用于说明场景？
- [ ] `aria-hidden="true"`、尺寸类由调用方传入？
- [ ] 已在「图标清单」登记？
