# OpenFOAM 运行时分发策略（T18）

- 决策日期：2026-09-08
- 结论：**v1 采用「环境探测 + 首次启动引导安装」**，捆绑精简运行时列为远期选项。

## 三个候选方案

| 方案                                        | 优点                                        | 缺点                                                                        | 结论                       |
| ------------------------------------------- | ------------------------------------------- | --------------------------------------------------------------------------- | -------------------------- |
| 捆绑精简 OpenFOAM 7 + 预编译 openInjMoldSim | 开箱即用                                    | 安装包体积激增（数百 MB）、需按平台分别构建、GPL 分发义务（附源码获取途径） | 远期（企业定制需求出现时） |
| 首次启动引导安装（探测 → 指引 → 复检）      | 安装包轻量、合规简单、与 probe 诊断天然衔接 | 用户需自行安装运行时                                                        | **v1 采用**                |
| 仅支持用户自备 OpenFOAM（PATH 探测）        | 零成本                                      | 新手门槛高                                                                  | 作为引导方案的兜底分支     |

## 实现要点（已落地部分）

- `probe_moldingfoam` 命令：检测 `blockMesh`（环境工具链）与 `foamRun`
  （模块化运行器）是否在 PATH；
- 未就绪时前端展示安装指引（依赖面板）；
- `OPENFOAM_HOME` 环境变量预留：后续版本用于定位非标准安装路径。

> 环境树），macOS 经 multipass 部署进虚拟机执行。上表保留为决策历史。

- macOS：分发前需 Apple Developer 证书签名 + 公证（codesign / notarytool）；

- 证书就绪前，安装包标注「未签名测试版」。
