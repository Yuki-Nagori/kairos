# T86 · 特殊工艺模块可行性（GAIM / 双色多组分 / 微发泡）

- 日期：2026-09-13
- 状态：规划结论文档（**不做实现**）
- 输入：Kairos case-contract v1.1 现状（`services::moldingfoam`）、材料模型字段、上游
  moldingFoam 已发布 bundle 的能力边界（v0.2.x）
- 结论摘要：**三个模块都要等上游多相 / 多材料能力落地**；Kairos 侧现在能做的只有数据位与
  面板占位，属于「先不欠架构债、但也不提前实现」的状态

## 一、现状（Kairos 侧可核实的事实）

| 维度     | 现状                                                                                                               |
| -------- | ------------------------------------------------------------------------------------------------------------------ |
| 相态     | case 的 `phaseProperties` 固定 `phases (melt air)`（两相：熔体 + 空气）                                            |
| 材料     | 单材料：Cross-WLF 黏度 + Tait PVT + hMelt；`mechanics`（E/ν）与 `filler`（类型/质量分数/长径比）已入库但不参与求解 |
| 边界     | `moldingInletVelocity`（浇口体积流量）/ `moldingVentVelocity`（排气）+ 闸口保压曲线                                |

| 工艺面板 | 单组熔体 / 模具温度、注射时间、V/P 切换、保压曲线、冷却时间                                                        |

## 二、逐项可行性

### 2.1 气体辅助注塑（GAIM）

- **能不能做**：**依赖上游**。GAIM 需要在熔体充填后注入气体（氮气）并让气体在芯部推进，
  物理上是「气-熔体-空气」三相 / 带气芯的黏性两相问题。
- **上游需要提供**：① 第二气体的相定义与物性字典（黏度/密度/压缩性）；② 气体入口边界
  条件（质量流量或压力曲线 + 注入时刻）；③ 气体-熔体界面（气芯）的追踪口径（VoF 三相还是
  独立场）；④ 穿透深度 / 气芯体积分数结果场。
- **Kairos 侧落点**：材料库加「气体介质」分组（物性表，走既有自定义材料导入）；工艺面板加
  GAIM 段（气体注射延迟、压力曲线、气量）；模具网络允许将某个 `Gate` 单元的介质标为气体
  （`RunnerElement` 加 `medium` 字段）；结果面板识别气芯场。
- **拆解**：一个任务（T89 `gaim-integration`），**开工条件 = 上游三相能力进入 release bundle**。
  在此之前只做「材料分组 + 面板字段」的数据位（可作为 T89 的第一步，不改 case 契约）。

### 2.2 双色 / 多组分注塑

- **能不能做**：**依赖上游**。至少需要两套熔体物性、两次注射时序、以及熔体-熔体界面的
  追踪（哪一层是第二种料）。当前 case 只有一组物性字典。
- **上游需要提供**：① 多材料字典（每个材料的 `momentumTransport` / `physicalProperties`
  命名空间化）；② 第二浇口 / 第二注射阶段的控制（时序 + 各自流量）；③ 界面追踪或
  材料分数场（`alpha.material2` 之类）；④ 双色件的结果量（各料层分布、结合面强度）。
- **Kairos 侧落点**：方案上允许多组材料（`Study.materialId` → 材料列表 + 各自浇口归属）；
  工艺面板按「组分」分组渲染时序；结果面板区分材料分数场。
- **拆解**：**暂不建档**。理由：双色是模具/机床层面的工艺，用户群与当前「单料 + 单腔」演示
  距离最远；等 GAIM 的「多相 / 多材料字典」能力落地后，双色可复用同一套机制（届时再建
  `multi-shot-integration`，预计 1～2 个任务）。

### 2.3 微发泡（MuCell）

- **能不能做**：**部分可近似**。微发泡的核心是「超临界气体溶于熔体 → 压力降触发泡核 →
  气泡长大使体积膨胀」。全解析需要群体平衡（population balance）或至少「气泡相 + 溶解气
  浓度」两场。
- **可行近似（若上游不做）**：把发泡效应折成「PVT 修正 + 表观黏度降低」——即在 Kairos 侧
  按发泡剂质量分数给 Tait / Cross-WLF 参数打折（经验模型），case 结构不变。这属于**模型
  级近似**，必须标注「非预测级」。
- **上游需要提供（全解析路线）**：① 溶解气浓度场与压力降判据；② 泡核 / 长大模型参数；
  ③ 膨胀后的密度场（结果与体积收缩相关）。
- **Kairos 侧落点**：材料 `filler` 旁边加 `blowing` 分组（发泡剂类型、质量分数、ep 参数）；
  工艺面板加「发泡剂量 / 背压」；PVT 修正走 case 生成期（不改求解器）。
- **拆解**：一个任务（T90 `mucell-pvt-approximation`），**可先行**——只依赖 Kairos 侧材料
  模型与 case 生成，不阻塞于上游；验收必须以「标注近似 + 真机跑通 + 与未发泡基线对比膨胀量级」
  为准，不承诺与商业软件数值一致。
