# T24 · PINN 熔融前沿预测研究 spike（结论文档）

- 日期：2026-09-08
- 结论：**有条件继续——限定为教学演示 / 交互式粗预测；不作为工程精度路线，不替代 openInjMoldSim 数值解**
- 复现：`pip install torch`（CPU 版即可）后 `python3 ai-docs/research/pinn-stefan-1d.py`，约 3 分钟

## 实验设置

一维单相 Stefan 问题（无量纲 α = 1，Ste = 1），与解析相似解对比：

- 解析解：s\*(t) = 2λ√t，u\*(x,t) = 1 − erf(x/2√t)/erf(λ)，λ = 0.620063（λ·e^{λ²}·erf(λ) = 1/√π 的二分求根）
- 网络：u(x,t) 为 2→32→32→32→1 的 tanh MLP；s(t) = t·softplus(s_net(t))——因子 t 精确满足 s(0)=0
- 损失：PDE 残差（液相配点拒绝采样）+ 壁面 u(0,t)=1 + 界面 u(s(t),t)=0 + Stefan 条件 ds/dt + u_x(s,t)=0（autograd）+ 初始 u(x,0)=0
- 训练：Adam，9000 步，lr 2e-3，CPU（Apple Silicon），约 3 分钟；无解析解监督（仅最终评估用）

## 定量结果（验收指标）

| 指标                                        | 数值      |
| ------------------------------------------- | --------- |
| 前沿位置 s(t) 最大相对误差（t ∈ [0.05, 1]） | **12.2%** |
| 温度场 u(x,t) 最大绝对误差（u ∈ [0,1]）     | **0.063** |
| Stefan 条件残差（训练末期）                 | ~5×10⁻⁴   |

## 解读

1. **基线配置下 PINN 能抓住物理形态**：前沿按 √t 增长、温度单调递减的定性结构都学到了，Stefan 条件残差收敛到 10⁻⁴ 量级——说明「界面 + Stefan 条件」的 loss 设计是可行的。
2. **12% 的前沿误差距工程精度差一个量级**：注塑件的收缩/翘曲评估通常要求前沿位置 <2%。社区同类实验（MIT 教学平台）的结论一致：小配置 PINN 的 Stefan 问题就是这个精度带。
3. **已知可收窄误差的手段**（本次未投入，属时间盒外）：L-BFGS 精修、边界条件硬约束（替代软惩罚）、自适应损失权重、causal 训练（按时间窗递进）。文献报告这些手段合计可把前沿误差压到 <2%，但训练成本与调参复杂度显著上升。

## 对 Kairos 的结论

- **继续**的唯一合理定位：教学演示（报告页嵌入「前沿传播对比图」）或求解前的实时粗预测（几秒内给出前沿量级）。两条用途都不要求 <2%。
- **终止**的方向：任何替代 openInjMoldSim 数值解、参与收缩/翘曲定量评估的设想——PINN 在可预见的投入内达不到该精度，且数值解本身已经可用且可信。
- 若未来决定投入「实时粗预测」，先做一次 2~3 天的增强 spike（L-BFGS + 硬约束 + causal），把前沿误差压到 <2% 后再评估集成；在此之前本任务保持关闭。
