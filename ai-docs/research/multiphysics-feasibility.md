# T87 · 多物理场耦合可行性（纤维取向 / 流固耦合）

- 日期：2026-09-13
- 状态：规划结论文档（**不做实现**）
- 输入：`material.filler`（T81 已入库）、`material.mechanics`（E/ν 预留）、T64 位移场消费、
  T65 变形显示（未完成）、T67 水路落地（未完成）、case-contract v1.1
- 结论摘要：**纤维取向→收缩各向异性依赖上游取向张量求解**；**流固耦合需要模具域网格，
  与当前「只建制品域」的架构冲突，判定为不做（除单向弱耦合外）**

## 一、纤维取向 → 收缩 / 各向异性

- **现状**：Kairos 材料模型有 `filler`（类型 / 质量分数 / 长径比）与 `mechanics`（弹性模量 /
  泊松比），但**都不进 case**；翘曲侧只有位移场 `D` 的消费口径（T64）。
- **物理链条**：流动诱导纤维取向（二阶取向张量 a₂）→ 各向异性黏度与热膨胀 → 各向异性收缩
  → 翘曲。缺任何一环都只能做经验修正。
- **能做的前提**：上游提供 ① 取向张量演化求解（Folgar-Tucker 或 iARD-RPR 类），② a₂ 的
  结果场写出（`<time>/a2` 对称张量），③ 由 a₂ 驱动的各向异性收缩系数口径（或由 Kairos 按
  a₂ + 纤维长径比经验折算）。
- **Kairos 侧落点**：
  - case：把 `filler`（类型 / 质量分数 / 长径比）写进材料字典（新增子字典，关键字待与上游
    冻结）——**这一步不依赖取向求解，可先行**；
  - 结果：对称张量场读取（当前 `tensor` 类场明确报错，需要新增一条「对称张量 → 主轴 +
    模量」的读法，与 T84 的矢量三分量通道同构）；
  - 展示：取向方向用矢量箭头 / 椭球，模量用标量云图；收缩各向异性作为派生算子（需要
    T44 派生管线支持按分量组合）。
- **上游需要提供**：取向场是否求解、写出格式（`volSymmTensorField`？）、是否算各向异性收缩。
- **拆解**：一个任务（T91 `fiber-orientation-chain`），**开工条件 = 上游取向场进入 release
  bundle**；第一步（filler 写进 case + 对称张量读取通道）可独立先行，验收只需 case 字典
  被求解器接受 + 张量场能读能画。

## 二、流固耦合（制品与模具变形交互）

- **现状**：Kairos 的网格**只有制品域**（体素 / Gmsh 四面体都只填制品），模具按恒温或 1D
  水路通道处理（T67）。没有模具域网格、没有接触 / 间隙模型。
- **真双向耦合需要**：模具域网格（或等效柔度模型）、制品-模具接触压力传递、模具变形对
  冷却水道位置的反作用。这三件事都要新网格引擎能力（模具域网格生成）与新的耦合迭代
  控制器（每步交换压力/位移），是**数量级更大的工程**。
- **可选近似（判定为可做的部分）**：单向弱耦合——用制品侧的压力场估算模腔压力 → 按模具
  材料的弹性模量估算型腔壁位移 → 作为翘曲结果的附加项展示。**这不需要模具域网格**，只需
  模壁等效刚度（用户输入或模具材料库）。它的价值是「量级提示」，不是预测。
- **结论**：真双向流固耦合 **不做**（明确记录：与「制品域单域求解」的架构冲突，且上游
  未规划）；若将来要，需先立项「模具域网格 + CHT」大任务（当前 C5 的三维水路 CHT 也未做）。
- **拆解**：不建档；在 architecture-status E2 写明「需模具域网格，当前架构不做」。

## 三、结论与落点

| 路径               | 结论                       | 依赖                             | 建档                                           |
| ------------------ | -------------------------- | -------------------------------- | ---------------------------------------------- |
| 纤维取向 → 收缩    | 能，等上游取向场           | 上游取向求解 + 张量写出          | T91（第一步可先行：filler 入 case + 张量读取） |
| 流固耦合（双向）   | **不做**                   | 模具域网格 + 接触模型 + 耦合迭代 | 不建档（写明理由与重评条件）                   |
| 流固耦合（单向弱） | 可做但优先级低（量级提示） | 模壁等效刚度输入                 | 暂不建档（等翘曲链路 M4 稳定后重评）           |
