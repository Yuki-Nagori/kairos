# T43 · 局部加密 / 边界层（体素引擎分级加密）

- 阶段：已实现并接入产品路径（体素引擎边界层 / 区域盒分级加密）；Gmsh 引擎不受影响
- 依赖：T06（体积网格生成）
- 优先级：P2

## 目标

补齐 C2 网格划分的最后两项：在体素 + 5-四面体保形分解引擎上支持
边界层（壁面邻域薄单元）与区域盒局部加密，供流动求解在壁面与关键
区域获得更高分辨率。

## 方案与范围（已实现）

保形依据：本引擎的 5-四面体分解以**全局索引奇偶**决定共享面上的
对角线，与单元尺寸无关——因此任意非均匀（分级）体素网格天然保形，
无需悬挂节点处理。这也是放弃「四面体最长边二分 + 级联」方案的原因：
后者在三维下面片对角线冲突需要绿色模板闭包，复杂度与风险不成比例。

- `kairos-core` `services/meshing.rs`：
  - `VolumeMeshParams.refinement: Option<MeshRefinement>`（DTO 双端镜像）；
  - `MeshRefinement::BoundaryLayers { layers, ratio }`：沿三轴在包围盒面
    附近按几何比率聚集单元（两端对称，层数 1..=4，比率 0.2..=0.9）；
  - `MeshRefinement::Region { region, levels }`：与区域盒相交的基础轴区间
    逐级对半细分（1..=2 级），三轴同时细分即盒内全方向加密；
  - 生成器改造为非均匀轴坐标：节点表、行扫描中心、占位填充全部按
    坐标数组工作；单元数上限守卫保留；
  - 过渡单元各向异性（min 边比下降）在质量报告中如实呈现。
- `src-tauri`：`generate_volume_mesh` 增加可选 `refinement` 参数。
- 前端：几何面板体素引擎行增加「边界层数」输入（1–4，空 = 不分级），
  以 `MeshRefinement` 可辨识联合透传 IPC。

## 当前实现边界

- 边界层分级贴包围盒面而非制件表面（体素引擎的包围盒近似）；
- 区域加密的过渡单元为各向异性长条单元（某轴细某轴粗）；
- 区域盒中心若恰好落在基础网格线上不会继续加密（对半细分语义）；
- Gmsh 引擎不受影响（其自身支持尺寸场，超出本任务范围）。

## 验收标准（已满足）

- 轴坐标构造单测：边界层端部薄 / 对称 / 归一化；区域细分只作用于相交区间；
- 生成级测试：区域加密后单元数增加、体积与保形不变（面共享 ≤ 2）、
  质量指标为正；分层模式壁面单元更薄；
- `MeshRefinement` 契约测试锁定 `mode` 标签与字段形状；
- 前端 store / 面板测试覆盖选项透传（kairos-core 行覆盖保持 100%）；
- `bun run verify` 全绿。
