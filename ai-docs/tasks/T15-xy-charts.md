# T15 · XY 曲线与探针

- 阶段：M4 后处理与体验
- 依赖：T13
- 优先级：P1

## 目标

提供注塑分析最常用的定量工具：任意位置的「物理量-时间」曲线、多案例对比与数据导出，让用户从"看云图"进阶到"读数字"。

## 范围

- 探针：在模型上拾取节点/点，建立探针列表（命名、颜色）；
- 曲线：探针位置的压力/温度/密度等量随时间变化，与视口时间轴联动（光标同步）；
- 进口曲线：注射压力、流量等全局曲线（来自求解日志与结果）；
- 多案例对比：同一位置跨研究/跨工艺的曲线叠加；
- 图表交互：缩放、平移、悬停读数、图例开关；
- 导出：CSV 导出曲线数据。

## 非目标

- 曲线拟合与数学分析工具；
- 报告生成（T17 负责把图表带进报告）；
- 自定义表达式/派生量计算（远期）。

## 交付物

- 图表组件（`src-web` 独立模块，Canvas/SVG 自绘或选型现成库——零依赖优先）；
- 探针管理 UI 与状态接入；
- 曲线数据服务（从结果模型取数）。

## 验收标准

- 万级数据点的曲线缩放/平移保持 60 FPS（对齐 T01 预算）；
- 探针取值与结果模型中的节点值一致（抽查单测）；
- 视口时间轴与曲线光标双向联动；
- 导出的 CSV 可被 Excel 直接打开且含单位表头。
