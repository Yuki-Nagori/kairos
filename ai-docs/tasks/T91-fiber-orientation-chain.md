# T91 · 纤维取向链路（取向场 → 各向异性展示）

- 阶段：E2（多物理场）
- 依赖：上游取向张量求解与写出；T44（派生管线）、T84（矢量/张量数据通道）
- 优先级：P3（等上游；第一步可先行）
- 状态：**待开工**
- 来源：[多物理场可行性](../research/multiphysics-feasibility.md)

## 目标

把纤维取向场接进 Kairos：材料填料参数进 case，结果侧能读对称张量场、显示取向方向与
模量，并为各向异性收缩（翘曲链路）留出入口。

## 范围

1. **第一步（可先行）**：`filler`（类型 / 质量分数 / 长径比）写进材料字典（关键字待与
   上游冻结）；对称张量场读取通道（当前 `tensor` 类场明确报错）——按「模量 + 主轴」解析，
   与 T84 的矢量三分量通道同构；
2. **第二步（等上游）**：取向张量 `a2` 结果场消费（矢量箭头 / 椭球叠加层）；
3. 各向异性收缩口径与 T64/T65 的翘曲链路衔接。

## 验收标准

- 第一步：case 字典被求解器接受（真机 checkMesh + 求解 exit 0）；对称张量场可读、
  模量云图可渲染、主轴方向可导出为叠加线段；
- 第二步：真实取向 case 的取向分布与流动方向定性一致（给出图与说明）；
- DTO 双端镜像 + 契约测试；`bun run verify` 全绿。
