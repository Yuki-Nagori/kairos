# T26 · UI 重构为 Moldflow 风格专业 CAE 工作台

- 阶段：M4 后处理与体验
- 依赖：T13（结果模型）、T14（视口引擎）、T16（设计系统）
- 优先级：P0
- 参考：`ai-docs/html/ui.html`（用户提供的 Moldflow 风格界面原型稿）

## 目标

将 Kairos 界面从简单卡片堆叠重构为 Moldflow 风格的专业 CAE 工作台：顶部菜单栏、左侧项目树、中央 3D 视口 + 工具栏、右侧属性/参数面板、底部状态栏与日志。视觉走现代深色路线。

## 范围

- 顶部菜单栏：Logo + 功能分组（文件/建模/网格/材料/工艺/分析/结果/工具/帮助）+ 右侧状态徽标；
- 左侧项目树：工程 → 研究 → 几何/网格/材料/工艺/结果的层级结构，支持右键操作和选中高亮；
- 中央：3D 视口（复用 T14 渲染器）+ 顶部工具栏（显示模式切换/剖切/测量）+ 底部状态栏（网格质量/材料/单元数/迭代进度）；
- 右侧属性面板：选中对象的参数详情（材料/工艺/结果概要），随选中对象动态切换；
- 底部日志：运行日志流、警告与错误高亮。

## 非目标

- 不做 Ribbon 折叠动画（保持简单点击切换）；
- 不做多文档 / 多窗口；
- 不做拖拽自定义面板布局（后续迭代）。

## 交付物

- `src-web/components/` 下新增 menu-bar / project-tree / view-toolbar / properties-panel / status-bar 组件；
- `src-web/components/viewport-panel.ts` 重构为嵌入式视口（去掉外层 card 包裹）；
- `src-web/main.ts` 组装完整 CAE 工作台布局。

## 验收标准

- 布局与 `ai-docs/html/ui.html` 原型稿视觉对齐；
- 所有既有功能（项目管理/材料/几何/网格/求解/结果/报告）在新布局中可用；
- verify 全绿。
