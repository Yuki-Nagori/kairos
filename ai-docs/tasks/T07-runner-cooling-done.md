# T07 · 浇口流道与冷却水路建模

- 阶段：M2 前处理
- 依赖：T05
- 优先级：P1

## 目标

让用户在一副模具里描述「塑料怎么进来、热量怎么出去」：浇口/流道系统与冷却水路的一维网络建模，并与型腔几何建立连通关系。

## 范围

- 一维单元模型：梁式单元（起点/终点、截面形状与尺寸、沿程属性），浇口类型（点浇口/侧浇口等）与流道（圆形/梯形等）；
- 冷却水路：回路定义（串联/并联）、介质参数（入口温度、流量或压降）、隔水板/喷流管占位类型；
- 与型腔的连通性建模：入口点落在制品表面并建立引用；
- 编辑体验：研究树 + 参数表两种方式，视口中的线段可视化（依赖 T14）；
- 连通性校验：孤立流道、断开水路、无浇口的型腔给出错误清单。

## 非目标

- 热流道与阀针的时序动态控制；
- 模具模板/镶件等结构件建模；
- 水路干涉的 3D 碰撞检查（远期）。

## 交付物

- core 一维单元与连通性模型 + 单测（重点覆盖校验规则）；
- 树/表编辑 UI 与校验错误面板；
- 样例工程：一模两腔 + 两路水路的演示数据。

## 验收标准

- 样例模具通过全部连通性校验并能导出给 T09 消费；
- 删除断开引用时给出明确的级联影响提示；
- 单元数量上千时树/表操作仍流畅（无感知延迟）。
