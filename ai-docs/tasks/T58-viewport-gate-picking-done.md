# T58 · 视口拾取放置浇口 + 吸附最近节点

- 阶段：B1（浇口建模 UX）
- 依赖：T45（视口拾取 pickCell）、T07（浇口建模）
- 优先级：P2（回流自 R1 全项目对照评审补充 1——"浇口位置必须设置在
  网格节点上"）

## 目标

模具网络面板增加「视口拾取放置」模式：进入模式后，下一次视口点击
（复用 pickCell 射线拾取）把命中单元中心 / 最近节点坐标写入浇口表单，
替代手填整数坐标。

## 范围

- viewport store 增加「放置模式」状态（对齐探针拾取的交互管线）；
- 命中点吸附：优先最近网格节点，无节点数据时用单元中心；
- 浇口表单坐标自动回填（用户仍可手改）；连续放置模式可选。

## 验收标准

- 拾取放置的坐标落在网格节点 / 单元中心上（对拍单测）；
- 放置后浇口列表立即可见，既有校验（模具网络连通性）不受影响；
- 未载入网格时拾取模式不可用并给出提示。
