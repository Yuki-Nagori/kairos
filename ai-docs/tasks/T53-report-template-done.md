# T53 · 模板化自定义报告（分区选择 + 标题 / 备注）

- 阶段：已实现并接入产品路径（报告标题 / 备注可自定义，六个分区可开关）
- 依赖：T17（报告导出）、T52（报告内容增强）
- 优先级：P2

## 目标

落地 C8「模板化自定义报告」：报告不再结构固定——用户可自定义标题与
备注，按需开关六个分区（材料与工艺 / 几何摘要 / 结果统计 / 探针数值 /
时间序列 / 云图与曲线），生成贴合用途的精简或完整报告。

## 方案与范围（已实现）

- `utils/report.ts`：
  - `ReportSections`（六分区开关）与 `ReportOptions`（title / notes /
    sections）DTO；`buildReportHtml(input, options?)` 缺省选项 = 默认
    标题 + 全部分区（既有调用零改动）；
  - 分区关闭时整节消失（含数据存在的情况）；备注按 `\n` 转 `<br />`
    并全量转义；标题空串 / 全空白回退默认标题；
- `useReportPanel` + 模板：`template` 响应式模板状态（标题输入 /
  备注文本域 / 六个分区勾选），生成时透传 `ReportOptions`；
- 模板选项不持久化（刷新回默认模板），持久化随研究结果关联任务。

## 当前实现边界

- 模板仅分区开关与标题 / 备注（无拖拽排版、无多套预置模板）；
- 模板选择不持久化。

## 验收标准（已满足）

- util 单测：自定义标题与备注渲染并转义、分区关闭整节消失、未关闭分区
  照常渲染、无选项回退默认标题且无备注节；
- 面板单测：标题输入与分区开关透传到生成的 HTML；
- `bun run verify` 全绿（utils / report 四维覆盖 100%）。
