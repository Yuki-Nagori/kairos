# T62 · 工艺参数合理性校验（填充工况量级）

- 阶段：B2/C4（求解器 · 流动分析的 Kairos 侧）
- 依赖：T08（工艺设置）、T06（网格报告提供件体积）、T61（浇口半径）
- 优先级：**P2**（真实件实测暴露的量级不匹配，属"提前拦住"型校验）

## 目标

在工艺提交前拦住「件体积 / 注射时间 / 浇口」三者量级明显不匹配的工况，并给出
建议值——而不是让求解器跑到压力 runaway、t 步塌缩、全场 NaN 才发现。

实测依据（2026-09-12，bundle v0.2.1，见 [e2e 报告](../reviews/e2e-solve-report.md)）：
873 cm³ 的真实件用默认工艺（注射 1 s）即 873 cm³/s，填充 1% 时门控压力已
5 MPa、3% 时 10² MPa 量级，压力 runaway → Courant 10⁷ → NaN；把流量降到
1/4 仍失稳。样例方盒（1 cm³、1 s）约 1 cm³/s，属正常量级。

## 范围

1. core（`services/process.rs`，纯函数）：
   - `estimate_fill_load(volume_mm3, injection_time_s, gate_radius_mm)` →
     `FillLoad { flow_rate_cm3_s, gate_shear_rate_s }`：
     体积流量 Q = V/t；浇口表观剪切速率 γ̇ = 4Q/(πR³)（圆管，给了半径才算）；
   - `fill_load_hints(volume_mm3, settings, gate_radius_mm) -> Vec<String>`：
     - Q 超常规注塑机包络（500 cm³/s）→ 给出件体积、当前流量与建议注射时间
       （V/500）；
     - γ̇ 超常见聚合物上限（5×10⁴ 1/s）→ 建议加大浇口直径或延长注射时间；
     - 体积缺失/非正 → 不做判断（没有网格信息时不打扰）；
     - 所有分支都避免除零（时间为 0、半径为 0/负值）。
2. 适配层：`check_process` 增加可选入参 `volume_mm3` / `gate_radius_mm`
   （来自网格报告与模具网络的 Gate 单元），问题清单与既有校验合并返回。
3. 前端：工艺面板「校验并应用到研究」时带上件体积（活跃几何的网格报告）与
   浇口半径（研究上第一个 Gate 单元），提示直接进既有问题清单 UI。
4. CLI：`pipeline run` 在生成 case 后打印工况提示（JSON 模式给出 `loadHints`），
   供无头验证与脚本使用。
5. 文档：本任务文件、任务索引、architecture-status 的 C4 条目与 timeline。

## 非目标

- 不估算**填充压力**：真机实测的 10² MPa 量级来自体素化薄通道 + 界面/空气相
  的求解行为，简单润滑模型无法可靠预测（会漏报或误报），故只做可辩护的量级
  检查（流量包络、浇口剪切）；
- 不做机器参数库（锁模力/螺杆直径/最大注射速率）——有了真实机型数据再加；
- 不改求解稳定性（属 moldingFoam 侧）。

## 验收标准

- 样例方盒（1 cm³、1 s）不产生任何提示 ✅；
- 873 cm³ 真实件用 1 s 注射产生「超出注塑机包络 + 建议注射时间 ≥ 1.7 s」
  提示 ✅（CLI 实测输出）；
- 细浇口 + 高流量触发剪切速率提示；注射时间拉长后该提示自动消失 ✅（单测）；
- 体积缺失、时间为 0、半径为 0/负值均不 panic、不误报 ✅（单测）；
- 前端面板校验调用携带上下文（面板测试锁定）；
  `bun run verify` 全绿。

## 当前实现边界

- 阈值是量级口径（500 cm³/s、5×10⁴ 1/s），来自实测与常见工艺窗口，不是机型
  精确包络；提示文案里写明「≈」与建议值，供用户判断；
- 剪切速率只在有浇口（Gate 单元）时检查——没有浇口时入口位置本身还是分带
  启发式（见 T61），算不出有意义的浇口半径；
- 检查是**提示**性质：进问题清单但不阻断应用（与既有工艺校验一致）。

## 回填（2026-09-13，上游 038 §6c 判据）

上游给出「浇口名义速度」判据并在求解器侧加了启动预警（`fillVelocityWarn`，
缺省 5 m/s），Kairos 侧据此扩展：

- 输入口径由「浇口半径」改为**浇口流通面积**（`inlet_area_m2`）：
  有浇口时取等效面积 πr²，CLI 直接取 case 里 inlet patch 的实测面积
  （`PatchAreas.inlet_m2`）；
- `FillLoad` 增加 `inlet_velocity_m_s = Q / A_in`，提示分档与上游一致：
  > 5 m/s 谨慎（粗网格/大流量易失稳）、> 20 m/s 判为工况不可行
  > （所需注塑压力多半超机台，可压缩两相求解器在浇口局部 Mach 接近 1 时失稳）；
- 浇口剪切速率改由面积反推等效半径（R = √(A/π)）计算，输入保持单一。

注：上游 5/20 的阈值来自旧「mm-as-m」数值基准下的 8.33 m/s；换算到 SI 后
它们恰好对应注塑工艺常用的浇口速度窗口（1~10 m/s 正常、20+ 不可行），
故按 SI 直接沿用。
