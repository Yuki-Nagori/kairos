# T71 · 面板折叠入口的可访问性（UiCard 标题栏按按钮暴露 + 长面板可折叠）

- 阶段：D0（平台底座 · 可访问性）
- 依赖：T26（工作台 UI）、T70（GUI 走查）
- 优先级：**P3**（不阻塞功能；影响读屏用户与自动化走查对长面板的触达）
- 状态：**已完成**

## 目标

可折叠卡片的标题栏对键盘与读屏可用；长面板能折叠，让同列后面的面板可见、可触达。

## 问题（GUI 走查实测）

- 折叠入口是带 `@click` 的 `div` + 一个箭头 `span`：可访问性树上只是静态文本，
  键盘也够不着（macOS 默认 Tab 不在非表单控件间跳转），等于「只有鼠标点标题栏」
  这一条路；
- 长面板不能折叠：模具网络一张卡片有 15 个数值输入 + 两张表单，运行时依赖清单
  随依赖数增长；
- 走查实测到的后果：可访问性桥对**每个容器按 DOM 顺序截断**（`main` 报
  「showing 0-63 of 130 items」），工艺设置面板排在第 64 条之后，**滚动也无法**
  让它进入树；折叠掉前面的长卡片是唯一能把它顶进预算的手段。

## 范围

1. `UiCard` 可折叠时标题栏按按钮暴露：`role="button"` + `tabindex="0"` +
   `aria-expanded`，回车 / 空格切换；不可折叠时不渲染这些属性（不引入空按钮）；
2. 两张长卡片开 `collapsible`：模具网络（流道 · 浇口 · 冷却）、运行时依赖；
3. 组件测试补「按按钮暴露 + 回车/空格切换」与「不可折叠时无按钮」两条断言。

## 非目标

- 全部面板默认折叠（保持默认展开的工作台观感）；
- 面板布局重排（右列按阶段置顶等）。

## 验收标准

- 折叠偏好仍写 localStorage 且重启保持（既有用例继续通过）；
- 真机走查：模具网络标题栏在可访问性树上为 pressable，折叠后工艺设置面板进入
  可访问性树（已实测）；
- `bun run verify` 全绿。

## 当前实现边界

- 只给两张长卡片开了折叠；材料库 / 结果 / 报告按需再扩。
