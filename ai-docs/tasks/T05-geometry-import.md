# T05 · 几何导入（STL）

- 阶段：M2 前处理
- 依赖：T03
- 优先级：P0

## 目标

让用户把制品几何带进 Kairos：以 STL 为第一种格式，完成导入、检查、展示与入树的完整体验，为网格生成提供输入。

## 范围

- STL 解析（ASCII 与 Binary），模型入库并挂到研究树；
- 单位推断与用户确认（STL 无单位，按尺寸启发式提示）；
- 几何健康检查：法向一致性、非流形边、退化三角形、零厚度面，输出问题清单与严重度；
- 视口线框/实体展示（依赖 T14 提供渲染能力前先用最小网格上传路径）；
- 包围盒、面积、三角形数等统计信息。

## 非目标

- STEP / IGES 等精确几何格式（后续任务评估 OCCT 绑定后再立项）；
- 几何修复建模工具（只做检查与建议，不自动改几何）；
- 装配体多实体布尔运算。

## 交付物

- core 几何模型与 STL 解析器 + 单测（含畸形文件容错）；
- 导入命令与前端交互（选择文件→检查报告→确认入库）；
- 研究树中的几何节点。

## 验收标准

- 10 万面 STL 导入 ≤ 2 秒（对齐 T01 预算）；
- 畸形 STL（坏法向/截断文件）不崩溃并给出可读诊断；
- 导入的几何能被 T06 网格生成直接消费。
