# T55 · 浇口位置分析（Gate Location 分析序列）

- 阶段：B2/B3（分析序列 + 结果管线）
- 依赖：T11（填充闭环）、T44（派生算子管线）、T49（结果展示）
- 优先级：P1（Moldflow 工作流标志性首步，回流自 R1 全项目对照评审）
- 来源：Moldflow「浇口位置」序列——无需预设浇口即可计算，输出适合度
  云图与最佳浇口位置建议（帮助页 GUID-84AA26DA 步骤 5）

## 目标

新增「浇口位置」分析序列：不设置浇口即可运行，输出**浇口位置适合度
云图**（覆盖全网格的标量场，走既有 ScalarField/云图管线）与 **Top-N
最佳浇口节点建议**（列表，供用户一键设为浇口）。

## 范围（实现方案开工时定，倾向 A）

- 方案 A（core 简化启发式）：遍历候选节点（或 Moldflow 式「浇口区域
  定位器」分区采样以控制计算量），对每个候选做轻量流动启发式评分
  （流动长度均衡性 / 壁厚可达性等），输出归一化适合度场；
- 方案 B（求解侧）：moldingFoam 若提供 gate location 模块则走 VM 执行；
- 分析序列下拉与方案任务窗格增加「浇口位置」项（无需浇口/工艺前置即可
  跑，对齐 Moldflow 行为）；
- 结果：适合度云图（结果面板选场）+ Top-N 建议列表（点击写入方案浇口）。

## 验收标准

- 无浇口预设时可选「浇口位置」序列并完成计算；
- 适合度云图在视口正常渲染，Top-N 建议可一键转为浇口；
- 纯函数评分逻辑单测 + 消融抽查；契约测试锁定新 DTO；
- 性能：中等网格（≥5 万四面体）候选遍历在预算内（开工时按 T01 定数）。

## 当前实现边界

- 简化启发式不承诺与 Moldflow 数值一致，只提供排序建议；
- 不含纤维 / 多型腔场景。
