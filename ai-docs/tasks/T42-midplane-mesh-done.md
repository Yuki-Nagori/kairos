# T42 · 中面网格（1D / 2.5D 快速分析路线）

- 阶段：已实现并接入产品路径（顶点配对中面抽取 + 梁耦合）；求解侧尚无中面消费
- 依赖：T05（几何导入）、T07（流道/浇口模型）、T41（共享射线加速与梁耦合逻辑）
- 优先级：P2

## 目标

对标商业软件的 Midplane 路线：从薄壁制品表面网格抽取中面（每单元带厚度），
以 2.5D 快速分析表达制品，杆系（流道/浇口）以一维梁单元耦合中面节点。

## 范围（已实现）

- `kairos-core` `services/midplane.rs`：
  - 顶点焊接与退化剔除（与双域网格同一容差口径）；
  - 顶点配对：每个表面顶点沿其相邻三角形的内法向发射射线，取最近对面命中
    （多射线取近，缓解棱边顶点平均法向斜穿问题）；中面节点 = 顶点与命中点中点；
  - 单元继承表面三角形连接；任一顶点未配对即丢弃该单元并在报告计数；
  - 杆系梁端点捕捉中面节点（捕捉容差默认对角线 1e-3）；失败端成为自由节点，
    完全重合的自由端（共享结点）按位置复用；
  - 射线求交复用 T41 的均匀格加速（`dualdomain::TriangleGrid` 提为 `pub(crate)`）；
  - `generate` 返回网格 + `MidplaneReport`（厚度统计、未配对顶点、丢弃单元、
    耦合/自由端点数）。

## 当前实现边界

- 顶点配对在棱边 / 角点处可能产生中面折痕或相邻单元厚度跳变——v1 以报告
  统计如实呈现，不做中面光顺；
- 厚板 / 实体件可能大面积配对失败：全部顶点未配对时明确报错并建议 3D 路线；
- 求解器（moldingFoam）尚不消费中面网格，产物当前用于前处理与统计。

## 验收标准（已满足）

- 平板中面节点落在半厚处、厚度统计正确；立方体棱边顶点多射线取近后全配对；
  部分配对场景丢弃计数正确；梁耦合与自由结点复用有单测
  （kairos-core 行覆盖保持 100%）；
- 契约测试锁定 `MidplaneReport` camelCase 形状；
- 前端 store / 面板测试覆盖空杆系、透传杆系、失败与报告渲染；
- `bun run verify` 全绿。
