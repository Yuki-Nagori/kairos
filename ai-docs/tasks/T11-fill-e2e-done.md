# T11 · 填充分析端到端闭环

- 阶段：M3 求解
- 依赖：T09、T10、T13、T14（最小渲染）
- 优先级：P0（全计划的分水岭里程碑）

## 目标

打通「导入 STL → 划网格 → 选材料 → 设工艺 → 求解 → 视口看流动前沿与压力云图」的最小完整闭环。完成即证明 Kairos 的产品假设成立：开源求解器 + 产品化外壳 = 可用的注塑仿真工具。

## 范围

- 全流程串联与状态引导：每一步的前置条件检查与下一步指引（哪些节点未完成一目了然）；
- 首次使用引导路径（样例工程一键加载）；
- 最小结果展示：流动前沿动画 + 压力/温度云图切换 + 时间步拖动；
- 全链路错误呈现：从网格失败到求解发散，每类失败的处置建议；
- 干净机器安装验证清单（与 T18 联动）。

## 非目标

- 精度标定与 V&V 报告（引用 openInjMoldSim 论文即可，暂不自建基准）；
- 保压/冷却阶段（T12）；
- 批处理/脚本接口。

## 交付物

- 端到端演示工程（dogbone 或等效样例）；
- 流程引导 UI 与结果最小展示；
- 端到端自动化测试（CI 可跑的冒烟路径，使用小网格控制时长）。

## 验收标准

- 新用户按引导在 30 分钟内完成一次完整填充分析并看到流动前沿动画；
- 端到端冒烟测试在 CI 稳定通过；
- 任一环节失败的提示都能指引用户回到正确的修复步骤；
- 全程 UI 无卡死（对齐 T01 预算）。
