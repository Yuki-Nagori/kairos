# T65 · 翘曲变形可视化（视口位移显示）

- 阶段：B2/C6（求解器 · 翘曲分析的 Kairos 侧，T64 的后续）
- 依赖：T64（位移场消费口径）、T39/T49（视口渲染与多视口）、T31（派生算子管线）
- 优先级：**P2**
- 状态：**待开工（回流）**——受两件事阻塞，见「阻塞与开工条件」

## 目标

在视口里按位移场显示翘曲变形：`变形 = 原位 + 倍数 × D(单元)`，与云图、
剖切、拾取、多视口联动共存（对齐 Moldflow 的 warp 显示）。

## 范围（开工时细化）

1. **矢量场分量数据通道**（core + IPC）：现在的结果读取只把矢量场取成模量
   （`parse_internal_vector_magnitudes`），变形需要三分量本身：
   `results` 增加分量读取（`Vec<[f64; 3]>` 或三个标量数组）、二进制通道
   （`field_binary` 的姊妹入口）与前端 store 对应字段。
2. **位移应用**（core 纯函数）：`RenderMeshData` 有 `face_cells`（每个三角面
   所属单元）。顶点被多个单元共享，直接按单元位移会让网格撕裂，故需要
   「顶点 → 邻接单元」聚合并取平均位移，再按倍数位移；纯函数 + 单测
   （合成场：已知位移下顶点位置精确；倍数为 0 时与原位一致）。
3. **视口控制**：变形场选择 + 倍数输入（对齐既有云图/剖切控件），与时间步
   联动；变形后法向重算（用既有 `computeVertexNormals`）。
4. 测试：core 单测 + 前端 store/组件测试；真机截图待 GUI 权限（见阻塞）。

## 契约（2026-09-13 上游确认）

| 场                                               | 类型                         | 量纲    | 说明                                                  |
| ------------------------------------------------ | ---------------------------- | ------- | ----------------------------------------------------- |
| `D`                                              | volVectorField               | m（SI） | 位移；**显示按 mm ×1000**                             |
| `sigma`                                          | volSymmTensorField           | Pa      | 残余应力张量（Kairos 当前不支持读取，展示用 sigmaEq） |
| `sigmaEq`                                        | volScalarField               | Pa      | 等效应力                                              |
| `T`                                              | volScalarField               | K       | 温度                                                  |
| `shrinkage` / `shrinkageTensor` / `voidFraction` | scalar / symmTensor / scalar | -       | 流动侧关联场（可选）                                  |

写出位置：`<time>/D`（writeInterval 控制）；样例见其仓库
`validation/warpagePlate` 与 `validation/shrinkBar`。

## 阻塞与开工条件

- **无真实场可验**：moldingFoam M4 的翘曲输出目前只有解析模型（曲率/挠度/
  残余应力公式），还没有 case 级位移场；T64 已按 OpenFOAM 惯例把 `D` 纳入
  「矢量场 → 模量」口径（可先看变形量云图），但三分量位移的字段契约要等
  M4 定稿。开工条件：M4 的位移场进入 case（`<time>/D`）并在真机上产出一个
  样例 case。
- **可视化验收需要桌面控制权限**：本机 macOS 对辅助功能/屏幕录制未授权，
  视口效果的截图验收做不了。开工条件：授权可用。

## 非目标

- 不做形变网格的场重映射（后处理仍基于原位网格的单元值）；
- 不做接触/装配干涉检查（属后续分析序列）。

## 验收标准（开工时生效）

- 合成位移场下顶点位移精确、倍数为 0 与原位一致（core 单测）；
- 变形显示与云图/剖切/多视口共存，时间步切换时位移随场刷新；
- 真实翘曲 case 的视口截图留档（含变形量云图 + 变形显示）；
- `bun run verify` 全绿。

## 当前实现边界

- 本任务只解决"显示"，不解决求解（M4 属 moldingFoam 侧）；
- 位移按单元平均到顶点，界面级显示用；不做逐点插值的高阶重构。
