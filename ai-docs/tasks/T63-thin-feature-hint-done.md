# T63 · 网格最小特征提示（体素尺寸 vs 壁厚）

- 阶段：B2/C4（求解器 · 流动分析的 Kairos 侧）
- 依赖：T06（体素网格）、T41（双域管线的厚度探测与 TriangleGrid）、T30（gmsh 引擎）
- 优先级：**P2**（真实件实测暴露的网格适配问题，属"提前拦住"型校验）

## 目标

在生成体素网格时提示「目标尺寸分辨不了薄壁」——薄壁会被体素化抹掉，或压成
单层单元使流动退化为薄板（润滑压降按 1/h² 放大）。

实测依据（2026-09-12，见 [e2e 报告](../reviews/e2e-solve-report.md) §5）：
真实件（控制器支架，5 mm 体素）底座被压成单层单元，流动路径退化；同一 case
在求解侧于固定填充分数处失稳。

## 范围

1. core（`services/thickness.rs`，新增）：
   - `probe_thickness(&TriangleMesh) -> ThicknessReport`：对（等距抽样的）三角面
     沿 ±法向做射线最近命中，取较小值作为局部壁厚；射线加速复用双域管线的
     `TriangleGrid` 与 `weld_surface`，不引入第二套几何工具；
   - **背面命中过滤**（`TriangleGrid::first_opposing_hit`）：只接受几何法向与
     射线同侧的命中。真实装配件的相邻零件/共面细节会给出 0.0x mm 的伪近距离，
     不做这层过滤会把 p05 从 0.38 mm 误算到 0.08 mm；
   - 判据用**薄壁表面占比**：`thin_fraction(2×目标尺寸) ≥ 5%` 才告警。真实件
     厚度分布是双峰的（件间间隙 <1 mm + 实体 ~14 mm），单看最薄值或某个
     分位数都会被离群点带偏，占比法对离群点稳健且直接回答"多大比例的表面
     分辨率不足"；
   - 抽样上限 4000 面（真实件 46.7 万面时探测耗时 <1 s，见实测）。
2. 报告与 UI：`MeshingReport` 新增 `thin_feature_hints: Vec<String>`
   （Rust ↔ TS 双端镜像 + 契约测试锁定），体素与 gmsh 两条网格命令都填充；
   几何面板在网格统计行下以琥珀色渲染提示。
3. CLI：`pipeline run` 打印「网格提示」并在 JSON 输出 `thicknessHints` 与
   `thickness` 统计（min/p05/median/samples）。
4. 文档：本任务文件、任务索引、architecture-status 的 C4 条目与 timeline。

## 非目标

- 不做逐单元的壁厚场（Moldflow 式厚度诊断）——只做"能否分辨"的量级提示；
- 不做网格自适应加密（T43 体素分级已有；本次只提示，不自动调整）；
- 不判断薄壁是否参与流动（件间装配间隙与真实薄壁在几何上无法区分）。

## 验收标准

- 20×20×2 mm 薄板：目标 1.0 mm（壁 = 2 个体素）不提示；目标 1.5 mm 提示并
  给出建议尺寸与 gmsh 备选 ✅（单测）；
- 开放网格 / 零面积面 / 空报告不产生样本也不误报 ✅（单测）；
- 真实件：3/5/8 mm 三档分别给出 42%/48%/51% 的薄壁占比提示，统计
  （min 0.00、p05 0.38、median 13.91 mm、3992 样本）稳定 ✅（CLI 实测）；
- 样例方盒（10 mm 立方体）：min=p05=median=10 mm、无提示 ✅（CLI 实测）；
- 前端面板渲染警告行（面板测试锁定）；契约测试锁定新字段；
  `bun run verify` 全绿。

## 当前实现边界

- 阈值（薄壁占比 5%）是量级口径：真实件大多会触发（3 mm 目标下 42%），
  提示语给出「若需分辨…」的条件式建议，不阻断网格生成；
- 抽样上限 4000 面意味着小特征可能落在抽样之外（真实件 3992/466988 面），
  统计是抽样估计而非全量；
- 装配件的间隙与真实薄壁在几何上不可区分，提示语同时提到两者。
