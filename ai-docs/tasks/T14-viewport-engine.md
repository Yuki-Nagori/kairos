# T14 · 3D 视口渲染引擎

- 阶段：M4 后处理与体验
- 依赖：T06（有网格即可开发）
- 优先级：P0

## 目标

打造 Kairos 的门面：一个对标 Moldflow 视口、但用现代图形技术实现的 3D 渲染引擎。性能是硬指标——百万三角形稳 60 FPS，云图与动画不降帧。

## 范围

- 渲染后端：WebGPU 优先，WebGL2 回退（Tauri WebView 能力探测）；
- 网格显示：实体/线框/半透明、边线叠加、网格质量着色（服务 T06 诊断）；
- 场云图着色：可配色标（科学色系）、图例、范围手动/自动缩放；
- 时间动画：时步序列播放/拖动/逐帧，帧率与结果加载解耦（未加载时步按需取）；
- 变形显示：位移场放大系数可视化（为翘曲预留，先支持任意位移场）；
- 视角与操作：旋转/平移/缩放（CAD 惯例：中键旋转等）、标准视图、适配窗口；
- 剖切平面与局部放大；
- LOD 与实例化策略：远处简化、按需精化，配齐性能埋点（供 T01 基准采样）。

## 非目标

- 光线追踪级真实感渲染；
- VR/AR；
- 视口内编辑几何。

## 交付物

- 视口引擎模块（`src-web` 内独立模块，canvas 封装 + 状态接入）；
- 性能埋点接入 T01 基准套件；
- 渲染能力探测与降级提示 UI。

## 验收标准

- ≥100 万三角形稳定 60 FPS（对齐 T01 预算，基准入 CI 报告）；
- 云图切换与时间步拖动无可感知卡顿；
- 不支持 WebGPU 的环境自动落到 WebGL2 并提示能力差异；
- 剖切、标准视图、适配窗口等操作符合 CAD 用户直觉（与 Moldflow 对照检查清单）。
