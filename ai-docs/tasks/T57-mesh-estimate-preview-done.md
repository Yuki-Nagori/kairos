# T57 · 网格预估单元数（生成前预览）

- 阶段：B1（网格划分 UX）
- 依赖：T06（体素引擎）
- 优先级：P2（立即做；回流自 R1 全项目对照评审步骤 4——"过粗失真、
  过细超时"）

## 目标

几何面板的目标尺寸输入变化时，**实时估算**生成后的单元规模，显示
「约 N 单元」，让用户在正式生成前调整边长：

- 体素引擎：精确估算（包围盒 ÷ target_size 的逐轴单元数 × 保形分解
  系数，与 meshing 同一套数学）；
- Gmsh 引擎：粗估（体积 ÷ (target_size³ × 经验系数)），标注"粗估"；
- 估算超 `MAX_TOTAL_CELLS` 上限时直接显示超限警告（代替生成后才报错）。

## 验收标准

- 目标尺寸输入防抖后实时显示估算值；体素估算与实际生成单元数一致
  （对拍单测：估算值 == 实际值）；
- 超上限场景显示警告且估算标红；
- 估算纯函数单测 + 消融抽查；Gmsh 粗估标注来源。
