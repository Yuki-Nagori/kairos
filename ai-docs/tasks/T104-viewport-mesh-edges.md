# T104：3D 视口网格边线

## 问题

生成体网格后，视口只填充灰色边界三角面，没有绘制单元边线。此前的法向修复不能解决这个显示缺口；空边界回退到 STL 还会掩盖体网格错误。

## 范围与验收

- [x] WebGL2 / WebGPU 默认叠加边界三角形的真实边线，保留遮挡、剖切和云图。
- [x] 边线索引仅在上传网格时构建，重复上传与销毁释放 GPU 资源。
- [x] 空体网格边界明确报错，不冒充原始 STL 表面。
- [x] 索引回归测试、浏览器渲染验证和完整 `bun run verify`。

## 实现边界

显示的是体网格的外边界三角形；内部四面体和剖切封口属于下一批待实现范围。STL 导入阶段显示其原始表面三角形。共享顶点和单元归属保持不变，避免破坏变形与拾取。

## 性能约束

边线索引为每个三角形 6 个 u32（24 字节），构建复杂度 O(边界面数)，逐帧不重建。复用已有顶点缓冲；共边允许重复绘制，避免额外哈希表及几何处理。

## 下一批：内部体单元检查

- [ ] 在 Rust 按剖切位置筛选四面体，提取可见单元的完整边界。
- [ ] 保持切口面与 owner 单元映射，支持内部单元拾取。
- [ ] 区分“表面裁剪”和“体单元剖切”的 UI 入口，并验证内部四面体拓扑。
