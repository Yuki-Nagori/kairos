# T47 · 视口完整剖切（三轴平面 + 位置 + 反向）

- 阶段：已实现并接入产品路径（三轴剖切平面）；WebGPU 后端与百万三角形性能
  验收归 T39
- 依赖：T14（视口引擎）、T45（相机快照基础设施）
- 优先级：P2

## 目标

把视口剖切从「单一 Y 平面、固定中点」升级为完整剖切控制：三轴任选、
位置连续可调、方向可反转——对标商业软件的截面查看能力。

## 方案与范围（已实现）

- `renderer.ts`：
  - 剖切片元着色条件泛化为「dot(p, normal) > offset 丢弃」，任意轴
    （含反向）由法向符号与偏移表达，一个平面零额外成本；
  - `setClipPlane(enabled, normal, offset)` 取代原 `setClip`；
  - `getMeshBounds()` 暴露网格包围盒（剖切位置滑块的世界坐标映射）；
  - FOV/eye 复用同一套轨道参数（与拾取共享 `getCamera` 快照口径）；
  - 视角重置时剖切面回到过包围盒中心（沿当前法向）。
- `render/math.ts`：`clipPlaneFromFraction(min, max, axis, fraction, invert)`
  纯函数——分数 → 平面（分数越界夹取到 0..1），与渲染器解耦可独立单测；
- `useViewportPanel`：剖切开关 + 轴选择（X/Y/Z）+ 位置滑块（0..1）+
  反向开关，任一变化即经 `applyClip` 同步到渲染器。

## 当前实现边界

- 平面法向限于 ±单位轴向量；任意斜面剖切（法向自由）需要配合 UI 法向
  编辑器，当前无使用场景驱动；
- 剖切为片元丢弃（无剖切截面封盖），大厚度件截面可见内部背面——
  与商业软件的「削切视图」一致，封盖渲染视需求另立任务；
- 剖切行为属命令式 WebGL 集成（vitest 覆盖率口径显式豁免），由真机验证。

## 验收标准（已满足）

- `clipPlaneFromFraction` 单测：分数 → 偏移映射、反向翻转、越界夹取；
- 渲染器类型检查通过（着色器行为由真机验证，与既有剖切实现同一豁免口径）；
- `bun run verify` 全绿。
