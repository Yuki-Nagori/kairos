# T16 · UI 设计系统与工作台布局

- 阶段：M4 后处理与体验
- 依赖：无（越早越好，设计先行避免返工）
- 优先级：P0

## 目标

确立 Kairos 的视觉与交互语言：信息架构以 Autodesk Moldflow 为基准（研究树 / 功能区 / 视口 / 结果图层 / 日志），视觉与交互全面现代化——好看、高效、一致。产出设计系统并改造现有工作台外壳，后续所有 UI 任务在此之上生长。

## 范围

- 设计 tokens：色彩（深色为主、可切浅色）、字体字号体系、间距、圆角、阴影、动效时长；
- 组件规范：按钮/输入/下拉/表格/树/标签页/徽标/空态/加载态/错误态，统一到 `ui.ts`（或演进为独立模块）；
- 工作台布局：Moldflow 式信息架构的现代化落地——左侧研究树、中央视口、右侧属性/参数面板、底部日志与状态栏、顶部功能区（按任务阶段组织而非按菜单组织）；
- 面板系统：可停靠、可折叠、尺寸与位置记忆（随项目或全局配置持久化）；
- 快捷键体系与命令面板（CAD 用户对快捷键敏感）；
- 空态与引导：新工程的引导式空态（下一步做什么一目了然，衔接 T11）。

## 非目标

- 像素级复刻 Moldflow 外观（对标信息架构，视觉走自己的现代语言）；
- 移动端/小屏适配；
- 多主题定制开放给用户。

## 交付物

- 设计 token 与组件规范文档（含 Moldflow 对照清单：每个 Moldflow 界面元素在 Kairos 的对应物）；
- 改造后的工作台布局骨架（替换现有占位）；
- 组件库初版 + happy-dom 组件测试。

## 验收标准

- 1080p 与 4K 下布局无溢出、无错位；
- 主题切换全界面一致（无遗漏的硬编码颜色——lint/评审核查）；
- 常用操作均有快捷键且可在命令面板发现；
- 布局与面板状态重启后还原；
- 交互密度不低于 Moldflow（同等操作步数以内完成等效任务）。
