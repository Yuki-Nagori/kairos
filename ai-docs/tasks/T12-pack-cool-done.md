# T12 · 保压与冷却分析

- 阶段：M3 求解
- 依赖：T11
- 优先级：P1

## 目标

在填充闭环之上启用 openInjMoldSim 的另外两个阶段：保压（压缩性与 PVT 效应、体积收缩演变）与冷却（模具温度场、水路换热、固化层生长），并把三阶段结果统一呈现。

## 范围

- 工艺到求解参数的扩展：保压曲线、冷却时间与水路参数进入 case 生成（扩展 T09 的生成器）；
- 阶段划分与求解策略：填充 → 填充+保压 → 填充+保压+冷却 的分析类型选择；
- 结果扩展：体积收缩/密度场、固化层厚度、模具温度、水路换热系数等新场进入结果模型（扩展 T13）；
- 与已发表 V&V 数据的数值对照记录（保压/冷却部分）；
- 三阶段结果的统一时间轴展示（跨阶段连续播放）。

## 非目标

- 翘曲变形分析（需结构求解器，独立立项评估，如 CalculiX 路线）；
- 纤维取向（openInjMoldSimF 变体，远期）；
- 模具热应力分析。

## 交付物

- 分析类型选择 UI 与扩展的 case 生成器 + 单测；
- 新结果场接入（模型 + 渲染色标）；
- 数值对照记录文档（与论文基准偏差表）。

## 验收标准

- dogbone 样例完成填充+保压+冷却全阶段求解，结果三阶段连续可播；
- 保压段压力衰减曲线与论文基准趋势一致（偏差记录在案）；
- 冷却水路参数修改能在结果中观察到对应温度场变化；
- 三阶段切换求解不重复已完成的阶段（可复用前置结果）。
