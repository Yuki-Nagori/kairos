# T20 · GPU 加速后处理算子

- 阶段：基础算子已实现；管线集成与性能验收未闭环
- 依赖：T19（GPU 抽象层）、T13（结果模型）、T14（视口）
- 优先级：P1

## 目标

把后处理管线中计算密集的环节放到 GPU 上，让大结果「秒开秒切」：等值面提取、切片投影、场重采样与降采样（LOD）、色标映射等算子用 wgpu compute 实现，四厂商显卡通用；CPU 只作正确性基准，不是运行时后端。

## 当前实现状态

已存在矢量模量、线性映射、阈值掩码和两场差值的 WGSL 原型，以及部分 CPU
参考实现和对拍测试。它们尚未接入结果加载、切片、LOD 或渲染帧管线；结果面板的
派生场目前仍调用 core CPU 实现。因此本任务不能视为“GPU 后处理已交付”。

后处理不再提供 CPU 运行时回退。CPU 实现只保留作单测与数值基准；无可用 GPU 的
环境须显示能力不受支持。

## 范围

- 算子清单（按收益排序）：
  - 场数据色标映射（LUT）——云图着色的每帧热点；
  - 体数据下采样 / LOD 金字塔生成——大网格流式加载的体验关键（联动 T13）；
  - 切片平面场投影——剖切视图实时重算；
  - 等值面提取（如流动前沿、固化层界面）；
  - 网格质量指标并行计算（反哺 T06 诊断）；
- 每个算子的 GPU/CPU 参考实现与结果一致性校验（容差内对齐）；CPU 不参与运行时选择；
- 算子管线调度：与渲染帧循环集成，避免读写冲突（GPU 资源分帧管理）；
- 性能埋点：每算子耗时入 T01 基准报告。

## 非目标

- 求解器数值内核 GPU 化（OpenFOAM 路线限制，远期独立评估）；
- 光线追踪渲染；
- 自研着色语言/框架（只用 WGSL）。

## 交付物

- GPU 算子库（WGSL compute shader + Rust 封装）+ CPU 参考实现；
- 与 T13/T14 的管线集成；
- 四厂商实测性能对照表（GPU vs CPU 加速比）。

## 验收标准

- 四类显卡实测：切片投影与 LOD 生成在 100 万四面体规模下较 CPU 实现加速 ≥ 5×；
- GPU 与 CPU 实现结果一致性：逐元素误差在容差内（单测覆盖）；
- 无 GPU 环境明确阻止后处理 GPU 算子并给出诊断，不会静默切换 CPU；
- 交互（拖动切片/改色标范围）为实时响应（≤ 1 帧延迟）；
- 任一厂商驱动上的已知问题均有规避开关或降级路径记录在兼容矩阵。
