## 验收范围

1. 运行时版本固定为 `moldingFoam v1.1.0`，CLI 与桌面端使用同一 case 生成和结果解析函数。
2. 每个 `run-XXX/` 至少保留：
   - `log.foamRun`：求解器原始 stdout/stderr，不做重排或摘要替换；
   - `started-at-ms`、`finished-at-ms`：Unix 毫秒时间戳；
   - case 输入、结果时间目录与 CLI 原始终端输出。
3. 参考结果集逐项对照：填充时间、切换压力、最大注射压力、入口压力；差异按原始单位和精度记录。
4. 失败运行必须保留失败日志、退出码、错误码和对应参数点；批次继续策略与 T92 一致。
5. 测试记录按执行时间归档到 `ai-docs/reviews/t100-runs/`，文件名使用时间戳，内容保留原始输出。

## CLI 入口

```bash
cargo run -p kairos-cli -- doe run \
  --factor '熔体温度=...' \
  --factor '注射时间=...' \
  --sample-box --out-dir <workspace> --solve
```

真实零件使用 `--stl <path>` 替换 `--sample-box`。运行前记录 `kairos-cli --version`、运行时版本、操作系统、架构和提交号。
