# T93 · 工艺参数自动寻优

- 阶段：E3（优化与自动化）
- 依赖：T92（DOE 汇总表）、T62/T74/T59（约束与预筛）
- 优先级：P3（等 T92）
- 状态：**待开工**
- 来源：[优化可行性](../research/optimization-feasibility.md)

## 目标

在给定目标函数与约束下自动搜索工艺参数：命中约束（浇口速度 / 剪切 / 填充覆盖）优先用
零成本校验筛掉，再按样本迭代求解。

## 范围

1. 目标函数定义（最大注射压力最小 / 填充时间最短 / 翘曲量最小，先做前两项）；
2. 约束复用既有校验（T74 浇口速度、T62 剪切、T59 填充覆盖预览）；
3. 算法：网格搜索 / 正交表 → 高斯过程贝叶斯优化（维度 ≤ 6）；
4. 失败运行处置：非物理结果高惩罚 + 重试一次；连续 3 次失败中止批次并报出失败参数点。

## 非目标

- 梯度类方法；代理模型精度承诺；国产化界面之外的调参向导。

## 验收标准

- 单目标、2～3 维的小算例上，寻优结果优于初始点并给出迭代轨迹（目标值随样本下降）；
- 约束违反的样本被排除且有计数；失败点被显式报出；
- 结论回填 architecture-status E3；`bun run verify` 全绿。
