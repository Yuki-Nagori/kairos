# T76 · case 材料热物性口径：Pr 由导热真值反算 + 冻死短射守卫开启

- 阶段：B2（求解器 · case 生成）
- 依赖：T04（材料库）、T66（case 单位制与排气对齐）
- 优先级：**P0**（导热率写错 5 个数量级，任何 case 的物理都不成立）
- 状态：**已完成**

## 现象（上游 v0.2.3 复测定论 + 本仓核实）

上游用回传的三帧（4.344/4.345/4.346）定论：熔体几乎 100% 低于固化温度 418 K、
|U| 峰值在入口单元 11 → 31 → 192 m/s、p 8.5 → 9.7 → 15 MPa → 非有限；**根因是
材料数据**：case 里 `transport { mu 100; Pr 4; }`，求解器按 k = mu·Cp/Pr 反推得
k = 62500 W/(m·K)（聚合物真值 0.2 量级，差 5 个数量级，真实 Pr 1e5–1e7），
熔体入模即冻、873 cm³/4 s 在 313 K 模里必然短射。与浇口生成缺陷（T72）叠加，
但修浇口救不了；`pressureRamp` 与 C 的失稳无关（压力阶跃不是触发点）。

本仓核实 `physical_properties_melt`：只采样了比热表，**从未使用材料的导热系数
表**，`mu / Pr` 是硬编码常数。

## 范围

1. **Pr 由导热真值反算**：`Pr = MELT_TRANSPORT_MU · Cp / k`，k 取导热系数表在熔温
   的插值；`mu` 保留 100 Pa·s 作为 const 输运的占位（黏度的物理模型仍由
   momentumTransport 的 CrossWlf 提供），并写明「k = mu·Cp/Pr 必须回到材料真值」；
   导热表缺失或非正值给明确校验错误；
2. **保压斜坡按注射时间定比例**：`packing { pressureRamp }` = 注射时间的 5%，
   夹在 [0.05, 0.5] s（求解器从 packing 子字典读，已对源码与日志回显确认）。
   依据：真实件（873 cm³ / 4 s）用求解器缺省 0.05 s 时切换后 2.5 ms 失稳
   （Courant 1.6e8），0.2 s 时跑到 endTime、填充 0.9957；
3. **冻死短射守卫开启**：moldingDict 写 `freezeOffTemperature = b5`（Tait 转变温度
   作无流温度代理）与 `freezeOffFraction = 0.01`——冷模 / 慢充工况转为明确的短射
   结果（封闸稳定收尾），而不是把冻结区推到非有限；
4. **测试**：Pr 反算（mu=100、Cp=2500、k=0.22 → 1.136364e6）、导热表缺失 / 非正的
   两条错误分支、moldingDict 的 freezeOff 与 pressureRamp 键、斜坡三段（下限 /
   线性 / 上限）；
5. **复测**：VM 内把修正灌回既有 case 复跑——B 仍通过；C 由「切换后 2.5 ms 失稳」
   转为跑到 endTime 8 s、填充 0.9957（详见
   [v0.2.3 复测报告](../reviews/v023-retest-report.md)）。

## 非目标

- 材料库补显式「无流温度」字段（替换 b5 代理，建议随材料库扩展一起做）；
- 浇口入口面口径与有效面积回显（T72）。

## 验收标准

- 生成 case 的 `k = mu·Cp/Pr` 等于材料导热真值（容差 1e-9）；
- 冷模工况不再以 NaN 收尾（正常完成或明确短射）；
- `bun run verify` 全绿（core 行覆盖 100%）。

## 当前实现边界

- 无流温度用 Tait 转变温度 b5 代理（材料库暂无显式字段）；
- `mu` 仍是占位常数，不参与 CrossWlf 黏度模型；
- 斜坡时长是「注射时间 5%、夹 [0.05, 0.5] s」的工程规则（两个用例上验证：
  样例盒 0.05、真实件 0.2），大件/超短注射仍可能落在区间外，需按上游反馈调。
