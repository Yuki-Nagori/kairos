# T82 · 双域 / 中面网格的求解消费

- 阶段：B2（求解器 · 网格口径）
- 依赖：T41（双域）、T42（中面）、T09–T11（case 生成与闭环）；**上游 moldingFoam 的降维支持口径**（哪种网格可降维、写出哪些量）
- 优先级：**P2**（C2 完成度的最大缺口：两条快速分析路线目前只到展示）
- 状态：**待开工**

## 目标

让双域与中面网格真正进入求解链路（当前 case 生成只吃 3D 体网格），
使「2.5D / 1D 快速分析」在 Kairos 里可用，而不只是视口里的网格。

## 现状

- T41/T42 已产出双域（表面厚度配对 + 杆系梁耦合）与中面（顶点配对）网格，
  面板可见、可载入视口；
- case 生成（T61/T66/T76）只处理 3D 体网格：`write_poly_mesh` 写体网格 +
  边界分带/浇口 portal；
- 状态文档两处标注「求解侧暂未消费」。

## 范围

1. **路线确认**：与 moldingFoam 对齐它支持哪种降维（壳 / 1D 梁 + 壳 / 等效厚度场），
   由此决定双域与中面哪条先接；
2. **case 生成**：把降维网格写成求解器可读的形式（厚度场 / 壳单元 / 梁段），
   浇口与排气边界在降维网格上的落位；
3. **结果映射**：求解结果回到 3D 表面展示（中面 → 上下表面、双域 → 表面三角形）；
4. 校验与提示：降维网格的质量判据（纵横比、匹配率，见 T56）纳入 case 前置校验。

## 非目标

- 替换 3D 体网格路径（3D 仍是精度基准）；
- 三维模具域 / CHT。

## 验收标准

- 双域或中面网格可生成 case 并求解出结果，结果可映射回表面云图；
- 与同件 3D 结果在填充时间 / 压力量级上对比给出偏差说明；
- `bun run verify` 全绿。
