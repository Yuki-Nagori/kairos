# T77 · STEP 镶嵌网格导入（补档）

- 阶段：B1/C1（CAD 接口）
- 依赖：T05（STL 导入：格式分发、入库与健康检查链路共用）
- 优先级：**P2**
- 状态：**已完成**（补档：实现早于本文件，范围按现状回填）

## 目标

STEP 文件里的**镶嵌网格**与 STL/IGES 同级导入，复用同一入库、健康检查与视口链路。

## 范围（现状）

- `services/step.rs`：`parse_step` / `parse_step_file` 支持 AP242
  `TRIANGULATED_FACE_SET` + `COORDINATES_LIST`，以及面化 B-rep 的 `POLY_LOOP`
  多边形面（扇形三角化）；
- 找不到可导入的镶嵌几何时给明确错误，提示以镶嵌形式重新导出；
- 命令 `import_step`；扩展名分发 `step` / `stp` → STEP（其余 → IGES/STL）；
- 解析结果落为 `TriangleMesh`，与 STL 共用入库与健康检查。

## 非目标

- 精确 B-rep（NURBS 曲面求值）导入——需评估 OCCT 绑定后另立项；
- 装配体结构（多实体层级）与布尔运算；
- 单位换算（沿用 STL 的启发式提示 + 用户确认）。

## 验收标准

- 单测覆盖两种镶嵌子集与「无可用镶嵌几何」的错误路径；
- 真机导入 STEP 文件得到与 STL 相同的几何摘要与健康检查输出。

## 当前实现边界

- 只吃镶嵌 / 面化子集；曲面片、装配、颜色层等一律跳过或报错。
