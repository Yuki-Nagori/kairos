# T18 · 打包分发与自动更新

- 阶段：M5 交付
- 依赖：T09（运行时策略）、T11（闭环成立）
- 优先级：P1

## 目标

让用户「下载 → 安装 → 打开就能跑通一次填充分析」：多平台安装包、OpenFOAM 运行时的分发方案、签名与自动更新通道。

## 范围

- 安装包：macOS（.dmg，签名与公证）、Windows（NSIS/MSI，签名）、Linux（AppImage 可选）；
- **OpenFOAM 运行时分发**（与 T09 策略联动，三选一并实现）：
  - 捆绑精简运行时 + 预编译 solver；
  - 首次启动引导下载安装；
  - 检测用户自备的 OpenFOAM 7；
- 自动更新：tauri updater 更新通道（版本清单、差分更新、灰度策略）；
- 崩溃与诊断：崩溃时收集环境信息（不含用户数据）的 diag 包导出；
- 版本与发布流程文档（语义化版本、发布清单 checklist）。

## 非目标

- 企业内网集中部署方案；
- 多版本并存安装器；
- 移动端。

## 交付物

- 三平台安装包流水线（挂接 T02 的 CI）；
- 运行时分发实现与用户文档；
- 更新通道配置与发布 checklist。

## 验收标准

- 干净的 macOS 与 Windows 虚拟机上：安装 → 启动 → 完成 dogbone 填充分析，全程无手工配置；
- 未装 OpenFOAM 的机器获得可理解的引导而非报错；
- 签名验证通过（macOS 公证、Windows SmartScreen 无未知发布者告警——在证书齐备前提下）；
- 自动更新从旧版本升级后用户数据（工程文件、设置）完整保留。
