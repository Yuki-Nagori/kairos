# T24 · PINN 熔融前沿预测研究 spike

- 阶段：下一阶段（远期研究，时间盒限制）
- 依赖：无（独立研究 spike）
- 优先级：P3

## 目标

时间盒研究：物理信息神经网络（PINN）在熔融前沿位置预测上的可行性——用一个小型一维/二维算例对比传统数值解，产出「值得投入 / 不值得」的明确结论。社区开源教学平台（MIT 许可）已实验过同类思路，可作为概念参考。

## 范围

- 一维 Stefan 问题（熔融前沿）的最小 PINN 模型（PyTorch）；
- 训练数据：由 kairos-core 现有数值解（或解析解）生成；
- 与解析解的误差评估与收敛性记录；
- 结论文档：在什么前提下面向 Kairos 有价值（如实时粗预测、教学演示）。

## 非目标

- 替代 openInjMoldSim 数值求解路线；
- 三维 / 真实材料参数规模；
- 生产化集成。

## 交付物

- spike 仓库 / notebook + 结论文档（`ai-docs/research/pinn-spike.md`）。

## 验收标准

- 一维算例 PINN 解与解析解最大相对误差给出定量数字；
- 结论文档明确「继续 / 终止」与理由。
