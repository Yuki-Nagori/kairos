# T22 · Gmsh 网格引擎集成评估与原型

- 阶段：下一阶段（网格质量升级）
- 依赖：T05、T06（体素方案已是可用基线）
- 优先级：P1

## 目标

评估并原型化用 Gmsh（成熟开源 3D 网格生成器）替代 v1 体素四面体方案：生成真正的 Delaunay 四面体网格，提升单元质量与边界贴合度。Gmsh 为 GPL——集成方式沿用 T09 的合规模式（外部子进程 / WASM 隔离，零源码入库）。

## 范围

- 选型评估：Gmsh 子进程调用 vs Gmsh WASM 构建 vs 纯 Rust Delaunay 替代（多准则：网格质量、速度、许可证隔离成本、维护性）；
- 原型：STL → Gmsh（几何入 STL → 3D 四面体 → 输出转换回 Kairos VolumeMesh）最小链路；
- 与 v1 体素方案在同一组样例上的质量指标对比（纵横比、边界贴合、单元数）；
- 评估结论写入决策文档（沿用 / 替换 / 混合：粗体素 + Gmsh 边界层）。

## 非目标

- 修改 Gmsh 源码或分发其修改版；
- 六面体 / 结构化网格；
- 局部加密与边界层（依赖所选引擎能力，二期）。

## 交付物

- 评估决策文档（含许可证隔离方案）；
- 可运行的转换原型 + 与 T06 相同口径的质量单测。

## 验收标准

- dogbone 样例生成 Delaunay 四面体 ≤ 60 秒（对齐 T01 预算）；
- 网格质量指标（纵横比）优于体素方案基线；
- GPL 隔离审计通过（仓库零 GPL 源码）。
