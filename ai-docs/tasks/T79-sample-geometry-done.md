# T79 · 内置样例几何（补档）

- 阶段：B1/C1（CAD 接口）
- 依赖：T05（导入链路）、T06（网格）
- 优先级：**P3**
- 状态：**已完成**（补档：实现早于本文件，范围按现状回填）

## 目标

内置样例立方体：没有几何素材时也能走通「导入 → 网格 → case → 求解」，兼作首用引导。

## 范围（现状）

- `importSampleBox(size)`（默认 10 mm 立方体），几何面板「导入样例」入口；
- 样例立方体经健康检查干净（单测断言），可直接生成体素体积网格；
- 被多处测试与真机复跑当夹具（样例盒 case、浇口/工况/单位制复验均以其为基准）。

## 非目标

- 内置更多样例件（异形件、模具、装配体）；
- 样例件随包分发为资产（当前由代码生成）。

## 验收标准

- 导入样例后健康检查无问题、体素网格可生成、可生成 case 并求解；
- 单测覆盖样例立方体的封闭一致性。

## 当前实现边界

- 仅立方体一种形状，尺寸可配。
