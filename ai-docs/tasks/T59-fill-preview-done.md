# T59 · 填充预览（轻量充填覆盖估计）

- 阶段：B2/B3
- 依赖：**T55**（复用其候选遍历 / 轻量流动启发式）、T07
- 优先级：P3（挂 T55 之后）

## 目标

对齐 Moldflow「填充预览」：设置浇口后，不改跑完整求解即给出**预计可
充填覆盖范围**的视图（绿色覆盖 = 从该浇口出发可充填），用于快速判断
浇口位置是否合理、是否存在无法充填的孤立区域。

## 范围（倾向复用 T55 的遍历框架）

- 以网格邻接图 BFS / 启发式流动长度估计充填覆盖，输出 0/1 或时间分级
  的标量场，走既有云图管线；
- 覆盖不全时提示未覆盖区域（面 / 单元列表计数）。

## 验收标准

- 预览计算耗时远低于完整求解（开工时定预算）；
- 覆盖场在视口渲染，未覆盖区域有明确计数提示；
- 启发式单测 + 消融抽查。

## 当前实现边界

- 预览为启发式估计，不承诺与真实求解前沿一致。
