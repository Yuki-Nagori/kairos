# T83 · 多型腔与流道系统参与填充

- 阶段：B2（求解器 · 浇注系统）
- 依赖：T07（流道 / 浇口建模）、T61（浇口 portal → inlet patch）
- 优先级：**P1**（C4 完成度的下一块：现在浇口只是一个入口面，流道不参与流动）
- 状态：**待开工**

## 目标

一模多腔与流道系统进入求解：熔体经流道分配后再进各腔，腔间填充差可见。

## 现状

- `RunnerElement`（流道 / 浇口）已在模具网络面板建模并做连通性校验；
- case 生成只把**浇口**当成 `inlet` patch（`GatePortal`：Gate 单元型腔端 +
  直径/2，等效面积 πr² 保底），流道本体不参与网格与流动；
- 多浇口在数据上支持（`gates` 可多个），但没有多腔分配策略。

## 范围

1. **流道几何进网格**：梁 → 体网格（或等效阻力模型），与制品网格合并 / 分区；
2. **多腔分配**：每个腔一个浇口的流量分配与边界条件（顺序填充 / 平衡填充的判据）；
3. **case 与面板对应**：模具网络面板的流道参数（直径 / 起止）如何落进 case；
4. 校验：流道-制品连通、浇口面积与流道截面的匹配（有效性提示，接 T72）。

## 非目标

- 热流道 / 阀浇口的时序控制（后续按需）；
- 流道内的详细传热（先按绝热或简化）。

## 验收标准

- 一模两腔样件（T07 的演示数据）跑通填充，两腔填充时间差有明确读数；
- 与单腔 case 对比，入口压力 / 填充时间偏差在可解释范围；
- `bun run verify` 全绿。
