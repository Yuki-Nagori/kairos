# T17 · 仿真报告导出

- 阶段：M4 后处理与体验
- 依赖：T13、T15
- 优先级：P2

## 目标

把分析成果变成可分享的交付物：一键生成结构化仿真报告（HTML → PDF），包含项目信息、材料与工艺参数、关键结果快照与曲线。

## 范围

- 报告模板：封面（项目/研究/日期/版本）、材料与工艺参数表、结果快照（视口指定视角与图层的截图）、关键曲线（T15 图表复用）、结论占位区（用户填写）；
- 模板定制：Logo、页眉页脚、主题色；
- 导出链路：HTML 渲染 → PDF（选型：系统打印管线或内置渲染，任务内评估）；
- 批量导出：多个研究/多个案例一次出报告。

## 非目标

- 在线协作评审与批注；
- 报告在线托管；
- Word 格式导出（PDF 先行）。

## 交付物

- 报告模板与渲染管线 + 单测（模板变量填充完整性）；
- 导出 UI（选择内容 → 预览 → 导出）。

## 验收标准

- dogbone 样例一键导出含 5 张以上快照与 2 条曲线的 PDF；
- 中文渲染无豆腐块（字体嵌入验证）；
- 100 页以内报告生成 ≤ 30 秒；
- 模板变量缺省时不产生「undefined」类占位污染。
