# T81 · 纤维 / 填料参数组（补档）

- 阶段：B1/C3（材料数据库）
- 依赖：T04（材料模型）、T80（CSV 列）
- 优先级：**P3**
- 状态：**已完成**（补档：实现早于本文件，范围按现状回填）

## 目标

把纤维 / 填料信息作为材料数据位入库并可见，为后续纤维取向与各向异性留接口。

## 范围（现状）

- DTO：`FillerGroup { kind, weight_fraction, aspect_ratio, note }`，
  `Material.filler: Option<FillerGroup>`（双端镜像 + 契约测试）；
- CSV 的 `filler` 列：`类型:质量分数:长径比:说明`（非纤维填料长径比填 1）；
- 材料面板展示填料行（`fillerRows`）。

## 非目标

- 纤维取向求解、各向异性黏度 / 力学 / 收缩（未接入，见 T87）；
- 填料对 PVT 的修正模型。

## 验收标准

- 契约测试锁定双端字段；
- CSV 解析与面板展示用例覆盖。

## 当前实现边界

- 纯数据位与展示，**不参与任何求解**（状态文档已注明）。
