# T06 · 3D 体积网格生成

- 阶段：M2 前处理
- 依赖：T05
- 优先级：P0

## 目标

把制品几何转成 openInjMoldSim 可求解的 3D 体积网格。注意：这是与 Moldflow 的关键差异点——本求解器是三维 CFD，网格路线为体积网格（四面体为主）+ 表面三角化（用于渲染与后处理），**不做**中面/双域。

## 范围

- 网格参数模型：全局尺寸、局部加密区（按面/体选择）、边界层选项；
- 网格生成引擎选型与集成（在成熟开源网格库中评估，标准：质量、速度、许可证兼容、语言绑定成本）；
- 网格质量指标：纵横比、最小/平均尺寸、雅可比等，输出网格统计报告；
- 表面三角网格与体积网格的双层存储与关联；
- 网格坏区诊断与局部重划的最小闭环；
- 生成过程进度回传与取消（走 Channel，UI 不阻塞）。

## 非目标

- 中面 / 双域（Dual Domain）网格——Moldflow 特有技术，明确不复制；
- 六面体与结构化网格；
- 网格手动编辑（只做参数化重划）。

## 交付物

- core 网格模型与生成引擎集成 + 单测（含网格质量计算）；
- 网格参数 UI 与统计报告界面；
- 与 T05 几何的衔接（研究树中网格节点）。

## 验收标准

- 官方 dogbone 类样例制品生成体积网格 ≤ 60 秒（对齐 T01 预算）；
- 生成的网格能被 T09 转换为合法 OpenFOAM case；
- 100 万四面体网格的统计计算与树展示不卡 UI（主线程阻塞 ≤ 50 ms）；
- 网格质量报告数值与所选引擎输出一致。
