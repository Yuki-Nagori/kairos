# T52 · 分析报告内容增强（几何摘要 / 探针数值 / 时间序列）

- 阶段：已实现并接入产品路径（HTML 报告新增三节：几何摘要、探针数值、
  探针时间序列；无数据自动省略）
- 依赖：T17（报告导出）、T45/T46（探针与时间序列）、T49（多实例视口）
- 优先级：P2

## 目标

把 C8「富文本/HTML 分析报告（配置快照 + 云图截图 + 曲线）」从基础版
（配置快照 + 视口/曲线截图 + 单行场统计）增强为覆盖后处理主要产物的
分析报告：几何与网格质量摘要、探针当前数值、探针时间序列逐采样表。

## 范围（已实现）

- `utils/report.ts`：`ReportInput` 新增可选 `geometryRows` / `probeRows` /
  `timeSeriesTables`；对应 HTML 节（几何摘要 / 探针数值 / 探针时间序列）
  仅在数据存在时渲染，键值与标签全部转义（沿用 escapeHtml）；
- `useReportPanel`：汇总几何摘要（首个几何的三角形数 / 尺寸 / 网格健康；
  体积网格报告存在时附引擎/节点/四面体/体积质量行）、探针当前值
  （含越界「越界」占位）、探针时间序列（timeS / value 逐采样）；
- 无几何 / 无探针时不渲染对应节（非「空表格」占位）。

## 当前实现边界

- 报告结构固定（T53 模板化任务做分区选择与自定义标题/备注）；
- 时间序列为逐采样全量表格，超长时间序列的表格体积未做分页。

## 验收标准（已满足）

- util 单测：新节按数据渲染、内容转义、缺省不渲染标题；
- 面板单测：几何摘要 / 探针数值 / 时间序列进入报告，无数据省略；
- `bun run verify` 全绿（utils 四维覆盖 100%）。
