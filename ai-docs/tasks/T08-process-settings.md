# T08 · 成型工艺设置

- 阶段：M2 前处理
- 依赖：T04
- 优先级：P0

## 目标

把「这模怎么注」变成结构化数据：建立注射/保压/冷却三段工艺的参数模型，向导式 UI 引导用户完成设置，输出能被求解器转换层（T09）直接消费的工艺数据。

## 范围

- 工艺参数模型：
  - 注射：熔体温度、注射速度/压力曲线、V/P 切换点、注射时间；
  - 保压：压力-时间曲线（多段）、冷却时间、开模时间；
  - 冷却：介质温度、流量、水路启用状态；
  - 模具环境温度；
- 与材料库联动：熔体温度默认区间等默认值来自所选材料（T04）；
- 工艺预设：保存/命名/复用工艺模板（跨研究共享）；
- 参数校验：量程、单位、曲线单调性，实时反馈；
- 向导式设置界面（分步骤表单 + 汇总页）。

## 非目标

- 自动工艺优化（远期）；
- 多材料多组分共注；
- 工艺仿真预演。

## 交付物

- core 工艺模型与校验 + 单测；
- 工艺向导 UI 与预设管理；
- 工艺 DTO 契约测试。

## 验收标准

- 从空工艺到完成设置的向导流程 ≤ 2 分钟（内置默认值可用）；
- 非法输入（超量程/坏曲线）被即时拦截并给出可读原因；
- 预设保存→应用后参数逐字段一致；
- 输出数据结构覆盖 T09 所需的全部工艺字段（以 openInjMoldSim 输入需求为准）。
