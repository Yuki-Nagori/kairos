# T92 · DOE / 正交试验编排

- 阶段：E3（优化与自动化）
- 依赖：T29（真机求解闭环稳定）、T32（无头 CLI）、T75（工作区布局）
- 优先级：P3（等 T29）
- 状态：**进行中**（2026-09-15：范围 1/3（提取）/4/5 的 core 侧已落地——矩阵生成、DoeRun 记录、CSV/JSON 汇总表、求解日志指标提取；范围 2 的目录 / 状态 / CLI 矩阵入口已落地；剩余的求解执行循环（逐次生成 case → 提交 → 提取指标 → 回填）待做）
- 来源：[优化可行性](../research/optimization-feasibility.md)

## 目标

按参数矩阵批量提交求解并产出汇总表：每次运行的工艺参数 + 关键结果指标 + 耗时 + 状态。

## 范围

1. 参数矩阵生成（正交表优先，L9/L16 起步；全因子仅 ≤3 维）；
2. 批量提交：**串行排队**（VM 单实例 / 本机单实例），每次运行独立 case 目录
   `cases/<方案 id>/run-XXX/`；
3. 结果指标提取（填充时间、V/P 切换压力、最大注射压力、入口压力）；
4. 汇总表落 `<工作区>/doe/<批次>/summary.csv` + `--json` 输出；
5. 失败运行显式标记（不静默丢弃）。

## 非目标

- 并发 / 多机调度；云端。

## 验收标准

- 同一矩阵跑 3 组正交试验，汇总表含每次运行参数 / 指标 / 耗时 / 状态；
- 人为制造一次失败运行（非法参数），汇总表标记该行且批次继续；
- 结论回填 architecture-status E3；`bun run verify` 全绿。
