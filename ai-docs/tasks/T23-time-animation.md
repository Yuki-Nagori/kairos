# T23 · 体素→表面场映射与时间步动画通道

- 阶段：下一阶段（T13/T14 深化）
- 依赖：T13（结果模型）、T14（视口）
- 优先级：P1

## 目标

打通「结果目录 → 全时步懒加载 → 视口动画」的数据通道：体素体心值映射到边界面着色，时间轴滑块拖动与播放控制，让 T14 视口从静态升级为可播放的填充过程动画。

## 范围

- 体素体心值 → 边界面着色映射（face→cell 索引已在渲染数据中）；
- 全时步懒加载管线：按时间轴顺序预取、缓存上限与淘汰；
- 动画控制：播放 / 暂停 / 拖动 / 逐帧 / 倍速；
- 云图色标范围自动跟随当前时步（可锁定）；
- 时间轴与 XY 曲线光标联动（T15）。

## 非目标

- 等值面提取（后续 GPU 算子，T20 扩展）；
- 大变形网格插值。

## 交付物

- 视口动画控制组件与加载管线；
- 流畅性埋点（接入 T01 基准）。

## 验收标准

- dogbone 结果在 32 个时间步上播放无卡顿（主线程阻塞 ≤ 50 ms）；
- 拖动时间轴响应 ≤ 1 帧；
- 未加载时步自动懒加载并显示加载状态。
