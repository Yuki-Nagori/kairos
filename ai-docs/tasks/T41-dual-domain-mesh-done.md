# T41 · 双域网格（表面 + 杆系耦合）

- 阶段：已实现并接入产品路径（厚度配对 + 梁耦合 + 报告）；求解侧尚无双域消费
- 依赖：T05（几何导入）、T07（流道/浇口模型）
- 优先级：P2

## 目标

对标 Moldflow Dual Domain 路线的前处理能力：以表面三角形（每单元带厚度）+
一维梁单元（流道/浇口）表达制品与浇注系统，为薄壁件的 2.5D 快速分析提供
网格产物。3D 求解路线（体素 / Gmsh + moldingFoam）不受影响。

## 范围（已实现）

- `kairos-core` `services/dualdomain.rs`：
  - 顶点焊接（与网格健康检查同一容差口径），零面积 / 焊接退化三角形剔除；
  - 厚度配对：三角形质心沿 ±法向射线取最近命中（双向取近，容忍法向不一致）；
  - 射线求交均匀格加速（3D DDA，目标 64³ 格），带早退；有暴力求交一致性测试；
  - 杆系耦合：梁端点按捕捉容差（默认对角线 1e-3）吸附最近表面节点成
    `BeamCoupling`；吸附失败按焊接容差去重后自成为自由节点；
  - `DualDomainReport` 统计：厚度 min/max/avg、未配对三角形、梁数、
    耦合/自由端点数。
- `src-tauri`：`generate_dual_domain_mesh` 命令（阻塞线程池执行，双域网格
  入会话缓存，返回报告）。
- 前端：几何面板「双域网格」动作 + 报告行；当前活跃方案的流道/浇口
  （`activeStudy.runnerElements`）作为杆系输入；修复几何时双域报告随之作废。

## 当前实现边界

- 厚度为质心射线最近命中，平板侧壁三角形会配到对面侧壁（≈ 外形尺寸）而非
  面厚——这是射线配厚对边缘单元的已知特性，报告中如实呈现不做修饰；
- 重复面（拷贝三角形）不去重——属于修复工具职责；
- 求解器（moldingFoam）尚不消费双域网格，产物当前用于前处理与统计；
- 捕捉容差为自动值（对角线 1e-3），暂不暴露 UI 参数。

## 验收标准（已满足）

- 立方体 / 平板用例厚度配对正确；梁端点耦合、自由节点去重、共享结点复用
  均有单测；DDA 与暴力求交在探针集上一致（kairos-core 行覆盖保持 100%）；
- 契约测试锁定 `DualDomainReport` camelCase 形状；
- 前端 store / 面板测试覆盖空杆系、透传杆系、失败与报告渲染；
- `bun run verify` 全绿。
