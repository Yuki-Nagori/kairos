# T80 · 牌号数据集扩充与 21 列 CSV 批量导入（补档）

- 阶段：B1/C3（材料数据库）
- 依赖：T04（材料数据模型与自定义材料）
- 优先级：**P2**
- 状态：**已完成**（补档：实现早于本文件，范围按现状回填）

## 目标

内置参考牌号覆盖多族 + 提供批量导入格式，便于把外部牌号数据成批带进来。

## 范围（现状）

- 固定 21 列表头（`CSV_HEADER`）：`name / manufacturer / family / n / tauStar /
d1 / d2 / d3 / a1 / a2 / b1m / b1s / b2m / b2s / b3 / b4m / b4s / b5 /
specificHeat / conductivity / filler`，与材料字段一一对应；
- `parse_custom_csv` 逐行校验并生成 id；表头与约定列序不一致时明确报错；
- 温度表列（比热 / 导热）用 `温度:值;温度:值` 形式，`filler` 列见 T81；
- 导入入口与 JSON 导入共用（`importCustomMaterials`，按 id 合并覆盖）。

## 非目标

- 生产级商业牌号数据（内置为公开文献参考值，`dataNote` 标注来源）；
- 在线牌号库同步。

## 验收标准

- 单测覆盖表头校验、逐行错误定位、温度表与填料列解析；
- 面板导入 21 列 CSV 后材料进入自定义库并可选用。

## 当前实现边界

- 列序固定，不做列名重排 / 缺列补默认。
