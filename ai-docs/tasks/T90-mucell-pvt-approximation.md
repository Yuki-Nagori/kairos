# T90 · 微发泡近似（PVT 修正路线）

- 阶段：E1（特殊工艺）
- 依赖：T04/T81（材料模型与填料分组）、T09–T11（case 生成）
- 优先级：P3（可先行，不阻塞上游）
- 状态：**待开工**
- 来源：[特殊工艺可行性](../research/special-process-feasibility.md)

## 目标

按发泡剂质量分数对 PVT / 黏度做经验修正，使 case 体现「微发泡后有效密度下降、流动阻力
降低」的量级效应。**明确是非预测级近似**，用于工艺敏感度对比而非定量预测。

## 范围

1. 材料模型加 `blowing` 分组（发泡剂类型、质量分数、修正系数），双端镜像 + 契约测试；
2. 材料面板增加发泡剂字段与「近似模型」标注；
3. case 生成期按修正系数调整 Tait 参数（有效密度）与 Cross-WLF（表观黏度）；
4. 结果面板/报告标注「微发泡近似」口径。

## 非目标

- 泡核 / 气泡长大的群体平衡模型（等上游全解析路线）；
- 与商业软件数值一致性的承诺。

## 验收标准

- 同一件同工艺下，发泡剂质量分数 0 与 2% 两档 case 的 PVT/黏度字典差异可读（字典快照对比）；
- 真机跑通（exit 0、无 NaN），且膨胀量级与经验模型一致（给出对比数字）；
- 面板与报告明确标注「近似」，`bun run verify` 全绿。
