# T86 · 扩展工艺模块规划（GAIM / 双色多组分 / 微发泡）

- 阶段：D/E1（特殊工艺模块）
- 依赖：T29（真机求解闭环）、上游 moldingFoam 的能力边界
- 优先级：**P3**（当前不在路线图上，先做可行性与依赖对齐）
- 状态：**规划完成**（2026-09-13）——GAIM 等上游三相能力（建档 T89）、双色暂不建档、
  微发泡近似可先行（建档 T90）；结论见 [特殊工艺可行性](../research/special-process-feasibility.md)

## 目标

为 E1 的三个特殊工艺模块给出可行性结论与拆解清单，避免「状态文档里的 [ ] 项永远没有落点」。

## 现状

- 气体辅助注塑（GAIM）、双色 / 多组分、微发泡（MuCell）均未实现；
- 求解侧是否支持（多相 / 多材料 / 气体入口）未知，需要与 moldingFoam 对齐；
- 工艺面板与 case 生成目前按单相熔体 + 空气建模（`phases (melt air)`）。

## 范围

1. **能力对齐**：逐项问清上游是否计划支持、需要什么字典与边界条件；
2. **Kairos 侧落点**：工艺面板字段、材料库（发泡剂 / 双组分）、结果展示的扩展点；
3. **拆解**：每个模块产出独立任务（含验收标准），或明确「不做」并记录理由。

## 非目标

- 本任务不做任何实现。

## 验收标准

- 三个模块各有一页可行性结论（能 / 不能 / 依赖谁）与拆解清单；
- 结论回填状态文档 E1 分节。
