# T87 · 多物理场耦合规划（纤维取向 / 流固耦合）

- 阶段：D/E2（多物理场耦合）
- 依赖：T64/T65（翘曲场与变形可视化）、T81（纤维 / 填料数据位）、上游能力
- 优先级：**P3**（规划任务，不做实现）
- 状态：**待开工**

## 目标

为 E2 的两条耦合路径给出可行性结论与拆解清单。

## 现状

- 纤维 / 填料参数已入库（T81）但**不参与求解**；
- 翘曲侧：Kairos 已能消费位移场（T64），变形可视化待 M4（T65）；
- 流固耦合（制品与模具变形交互）在 Kairos 侧没有任何模型：网格只有制品域，
  模具按恒温 / 1D 通道处理（T67）。

## 范围

1. **纤维取向 → 收缩 / 各向异性**：上游是否有取向张量求解；其结果如何影响
   PVT / 力学参数（与 T64 的翘曲链路衔接）；
2. **流固耦合**：是否需要模具域网格与双向耦合；与 C5 冷却（T67）的边界；
3. **拆解**：每条路径产出独立任务或明确不做的理由。

## 非目标

- 本任务不做任何实现。

## 验收标准

- 两条路径各有一页可行性结论（能 / 不能 / 依赖谁）与拆解清单；
- 结论回填状态文档 E2 分节。
