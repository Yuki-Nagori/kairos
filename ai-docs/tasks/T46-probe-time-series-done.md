# T46 · 探针时间曲线与时间轴联动

- 阶段：已实现并接入产品路径（时间序列加载 + 双向联动）；多视口联动另行规划
- 依赖：T13（结果模型）、T15（XY 曲线与探针）、T45（空间拾取）
- 优先级：P2

## 目标

补齐 C7「曲线 / 时间轴联动」：探针不止能标注当前时刻的值，还能沿结果
目录的时间步绘制「值-时间」曲线，并让图表与视口共享同一时间轴——
图表跳转时间步，视口云图与探针读数同步刷新。

## 范围（已实现）

- `stores/results.ts`：
  - `probeTimeSeries`（每探针一份「timeS → value」采样）与
    `probeSeriesField`（序列对应的原始场名）；
  - `loadProbeTimeSeries()`：遍历目录时间步逐个加载原始场，收集各探针
    取值；越界探针回退 0；遍历中命中原时间步时回填展示态（图表加载
    完成后视口停留在进入前的时刻）；移除探针时同步过滤序列；
- `useXyChartPanel` + 模板：
  - 模式选择「空间分布 / 探针时间曲线」；时间模式下每探针一条曲线
    （配色轮换），坐标轴为「时间步（序）」；
  - 「跳转到时间步」选择器：按目录时间步加载原始场 → 视口云图与探针
    数值经既有 watch 链路同步刷新（双向联动的图表 → 视口方向；
    视口 → 图表方向由 loadedField watch 覆盖）；
  - 守卫：目录 / 探针 / 已加载场缺失时静默不触发。

## 当前实现边界

- 时间序列逐时间步整文件加载（OpenFOAM 文本 → f64），时间步多时耗时
  线性增长；二进制分块与缓存淘汰属大结果数据链（见 C7 备注）；
- x 轴为时间步序号而非物理时间刻度（等距绘制）；
- 多视口联动不在本任务（另行规划）。

## 验收标准（已满足）

- store 单测：采样数值与顺序、原时间步恢复、越界回退、缺失守卫、
  加载失败报错、移除探针同步过滤；
- 面板单测：时间模式下加载调用与画布绘制、跳转选择器按所选时间步
  加载原始场、空选择静默；
- 前端四维覆盖率保持 100%；`bun run verify` 全绿。
