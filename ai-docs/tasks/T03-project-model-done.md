# T03 · 仿真项目模型与持久化

- 阶段：M1 数据底座
- 依赖：无
- 优先级：P0

## 目标

建立 Kairos 的领域数据骨架：项目（Project）→ 研究（Study）→ 各领域对象（几何/网格/材料/工艺/结果引用）的分层模型，以及可靠的单文件工程格式。后续所有任务的数据都挂在这副骨架上。

## 范围

- 领域模型（`kairos-core`）：Project / Study / 对象引用与元数据（命名、创建/修改时间、缩略图占位）；
- 工程文件格式：单文件 `.kairos`，要求——自包含、schema 带版本号、写入原子化（防损坏）、可向后迁移旧版本；
- 命令层：新建 / 打开 / 保存 / 另存为 / 最近项目列表；
- 前端：项目对话框服务、状态接入、最近项目入口；
- 大二进制（网格、结果）与工程元数据的引用关系约定（内嵌或外置文件的边界先定义清楚）。

## 非目标

- 云端同步与协作；
- 多文档多窗口；
- 工程文件加密。

## 交付物

- core 模型与持久化实现 + 单测；
- 命令与前端服务接入；
- `.kairos` 格式规范文档（schema 与版本迁移规则）。

## 验收标准

- 保存→打开往返后数据零丢失（属性级单测）；
- 旧版本 schema 文件可被新版本打开并自动迁移；
- 断电/强杀进程后的半写文件不会损坏既有工程（原子写验证）；
- 契约测试覆盖新 DTO。
