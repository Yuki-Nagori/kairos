# T78 · 几何修复工具（补档）

- 阶段：B1/C1（CAD 接口）
- 依赖：T05（健康检查：问题分类是修复的输入）
- 优先级：**P2**
- 状态：**已完成**（补档：实现早于本文件，范围按现状回填）

## 目标

在健康检查给出的问题清单之上，提供一键修复动作，把「检查」推进到「改到可用」。

## 范围（现状）

- `services/repair.rs::repair_mesh` → `(TriangleMesh, RepairReport)`：
  重复顶点焊接、退化面移除、边界环孔洞填充、法向 BFS 一致化、自交对检测计数；
- 修复报告随几何摘要回传，几何面板的「修复」动作触发并展示。

## 非目标

- 布尔运算、曲面重建、拓扑重映射到精确 CAD；
- 自动消除自交（当前只检测计数）。

## 验收标准

- 单测覆盖各修复项与「修复后健康检查清零」；
- 面板「修复」动作后摘要与报告同步刷新。

## 当前实现边界

- 启发式、网格级修复；自交只报不改。
