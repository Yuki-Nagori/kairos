# T13 · 结果数据模型与流式读取

- 阶段：基础目录扫描与场读取已实现；大结果管线验收未闭环
- 依赖：T09
- 优先级：P0

## 目标

把 OpenFOAM 的时间步结果变成 Kairos 的统一结果模型，并最终实现分块流式加载、缓存、按需精化。当前实现仅覆盖时间目录扫描、文本 `internalField` 读取、标量场和已折算为模量的少量矢量场；尚不是大结果数据管线。

## 当前实现边界

- 结果文件目前整文件读入内存并解析为 `Vec<f64>`，通过 JSON DTO 交给前端；
- 尚无二进制分块、懒加载预取、缓存淘汰、重新求解失效、单位元数据或完整矢量分量；
- 结果也尚未持久挂接到 `Study`。因此 500 MB 首帧、主线程和缓存相关验收均未通过。

## 范围

- 结果数据模型：标量场（压力、温度、体积收缩、固化层…）、矢量场（速度）、标量序列（流动前沿时间、进口压力曲线）、时间步元数据；
- 转换器：OpenFOAM 输出目录 → Kairos 结果存储（后台线程/进程执行，含单位换算）；
- 流式加载：元数据先到、首时步秒开、其余时步按需懒加载；
- 缓存策略：转换后的中间格式缓存与失效（重新求解后自动失效）；
- 结果与研究的挂接（T03 模型中的结果引用）。

## 非目标

- 结果的统计后处理指标（缩痕预测等，远期）；
- 多物理场耦合结果的对比分析（远期）。

## 交付物

- core 结果模型、转换器与缓存 + 单测（以 dogbone 结果为固定样例）；
- 结果 DTO 契约测试；
- 加载进度 UI 接入。

## 验收标准

- 500 MB 级结果：首帧展示 ≤ 2 秒，期间主线程阻塞 ≤ 50 ms（对齐 T01 预算）；
- 转换器对不完整结果（求解中途取消）可读取已完成部分并明确标注；
- 重新求解后旧缓存不串数据（失效单测）；
- 任一时步的字段值与 OpenFOAM 原始输出抽查一致。
