# T88 · 优化与自动化规划（DOE 编排 / 工艺参数寻优）

- 阶段：D/E3（优化与自动化）
- 依赖：T29（真机求解闭环）、T32（无头 CLI 与批处理入口）
- 优先级：**P3**（规划任务，不做实现；两条都以「求解闭环稳定」为前提）
- 状态：**待开工**

## 目标

为 E3 的两条路径给出落点与拆解，避免状态文档的 [ ] 项没有对应任务。

## 现状

- 无头 CLI 与批处理入口已就绪（T32：`project / mesh / solve / results /
pipeline run`，`--json` 输出）；
- **DOE / 正交试验编排**：未实现。CLI 已具备单次运行能力，缺参数矩阵生成、
  批量提交与结果汇总；
- **工艺参数自动寻优**：未实现。依赖结果的闭环迭代（目标函数定义、
  收敛判据、失败回退）。

## 范围（规划）

1. **DOE**：参数维度与取值方式（正交表 / 全因子 / 拉丁超立方）、批量提交的并发与
   资源约束（VM 单实例 → 串行排队）、结果表（每次运行的工艺-结果指标）；
2. **寻优**：目标函数（填充时间 / 锁模力 / 翘曲量…）与约束（浇口速度、剪切、
   短射），算法选型（网格搜索 → 贝叶斯优化），失败运行的处置；
3. **与工作区的关系**：每次运行的结果目录结构（接 T75）；
4. **拆解**：两条路径各产出独立任务与验收标准。

## 非目标

- 本任务不做任何实现；
- 云端并行 / 多机调度。

## 验收标准

- 两条路径各有一页可行性结论与拆解清单（含数据布局与资源约束）；
- 结论回填状态文档 E3 分节。
