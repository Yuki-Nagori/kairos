# T04 · 材料数据库

- 阶段：M1 数据底座
- 依赖：T03
- 优先级：P0

## 目标

建立热塑性材料的数据底座。材料是注塑仿真的物理输入核心：openInjMoldSim 使用 Cross-WLF 黏度、Tait PVT 与温度相关热物性，材料库必须能完整承载这些参数。

## 范围

- 材料数据模型：牌号（Grade）/厂商/材料族，参数分组——流变（Cross-WLF 七参数）、PVT（Tait 方程参数）、热性能（比热、导热系数随温度表）、力学（弹性模量、泊松比、热膨胀，为后续结构分析预留）；
- 参数合法性校验（量程、表格单调性）；
- 内置示例材料集（若干常见非结晶/半结晶牌号，数据来源与免责声明注明）；
- 自定义材料：创建 / 编辑 / 复制 / 删除 / JSON 导入导出；
- 前端材料管理界面：浏览、搜索筛选、参数详情页（含曲线预览）。

## 非目标

- 商业材料库（如 Moldflow 材料库）的导入与解析——版权红线，不做；
- 由流变实测数据拟合模型参数的工具（远期另立任务）；
- 材料相容性、降解等化学模型。

## 交付物

- core 材料模型与存储 + 单测；
- 内置示例材料数据文件；
- 前端材料管理界面；
- 材料数据 JSON 规范文档。

## 验收标准

- 每个内置材料通过参数完整性校验，并能被工艺设置（T08）引用；
- 曲线预览与参数表一致；
- 导出→删除→导入后数据逐字段一致；
- 契约测试覆盖材料 DTO。
