# T31 · 派生结果算子（对标 data_transform）

- 阶段：基础派生场 UI 与 core CPU 算子已实现；GPU 管线和性能验收未闭环
- 依赖：T19、T20（GPU 基础设施与算子）
- 优先级：P2

## 目标

对标 moldflow-api `data_transform` 的「用户派生绘图」概念（T25 研究建议 #4）：对已加载结果场做标量/矢量运算生成新场，供图表与视口展示——如速度模量（已有）、压力归一化、场差值、温度切片。

## 当前实现边界

结果面板当前暴露归一化和阈值掩码；它们通过 `kairos-core` 的 CPU 实现完成。线性
映射、两场差值和对应 WGSL 原型尚未形成“选择两场 → GPU 执行 → 结果目录登记”的
产品通路，且没有 100 万值的性能基准。因此不应将本任务描述为 GPU 加速已完成。

## 范围

- 算子目录扩展：归一化、线性映射、两场差值、常数阈值掩码（WGSL 实现 + CPU 参考实现 + 一致性测试，沿用 T20 模式）；
- 前端：结果面板增加「派生场」操作（选择源场与算子 → 生成新场入目录）；
- 性能：1M 值派生运算 GPU 路径较 CPU ≥ 5×（沿用 perf-budget 算子标准）。

## 非目标

- 自定义表达式解析器（固定算子集即可）；
- 三维体渲染。

## 交付物

- 新算子（WGSL + CPU 参考 + 测试）；
- 结果面板派生场 UI。

## 验收标准

- 新算子 GPU/CPU 一致性测试通过；
- 派生场可在 XY 图表与视口云图展示；
- 基准达到 ≥ 5× 加速标准。
