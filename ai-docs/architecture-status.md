# Kairos 架构状态与验收清单

对标商业注塑成型软件的标准架构（前处理 / 求解器 / 后处理 / 扩展模块），
逐分支记录实现、集成与验收的真实状态；它是功能状态的权威来源，任务文件名 `-done`
只表示有实现提交。

**特殊标注**：`🏷️ moldingFoam` = 该能力由
[Yuki-Nagori/moldingFoam](https://github.com/Yuki-Nagori/moldingFoam)
（基于 OpenFOAM-14 的注塑求解项目）承担，Kairos 侧只负责调用、数据准备
与结果消费（GPL 隔离：子进程 + 文件交换）。

> 状态截至 2026-09-12（T44–T53 后 + 当日整体评审修复批次）。任务编号（Txx）对应
> ai-docs/tasks/ 索引。**完成度百分比只在本文件「里程碑对照」表维护**——
> timeline 与任务索引不复述该数字（单一事实源）。

## 状态口径

- `- [x]`：功能已实现并接入当前产品路径；
- `- △`：仅有基础实现或原型，关键集成、性能或跨平台验收未闭环；
- `- [ ]`：尚未实现；
- `- ⚠`：外部依赖或已知问题阻塞。

“完成度”仅衡量实现覆盖，**不替代性能、三端兼容与真实求解验收**。后处理以
硬件加速 GPU 为运行前提：无可用 GPU 时显示能力不受支持，CPU 代码只作数值对拍，
不再作为运行时回退。后处理渲染路线见 [T39](tasks/T39-postprocess-renderer-done.md)。

### C4.1 浇口位置分析（不需要求解器的启发式序列）

- [x] 浇口位置分析（T55）：`services/gate_location.rs` 纯函数评分——候选限**表面单元**，
      评分 = 流动长度均衡（1 − 最长流动距离 / 包围盒对角线）× 壁厚可达性（单元最短高

      实测 62.5 万四面体 / 399 候选 = 296 ms（release）；口径标注「启发式建议，非求解结果」

- [x] 填充预览（T59）：`services/fill_preview.rs` ——单元共享面邻接 + 从浇口单元出发的
      多源最短路（Dijkstra，边权取形心距离），输出可充填覆盖（图连通）与归一化到达序场
      （0 = 浇口、1 = 最远可达，直接进视口云图）；断连区域给出单元计数与占比告警，
      浇口离件过远时提示核对坐标。实测 62.5 万四面体 / 单浇口 = 168 ms（预算 3 秒）；
      口径标注「启发式预览，非求解结果」
