# Kairos 基线报告

本目录保存可复现的 Kairos 仿真基线、实验对照和逐次复核结论。报告只记录脱敏后的参数、摘要、误差和时间戳；受限原始材料曲线与专有数据库文件不进入仓库。

## 报告目录

- [Mug 基线与实验对照](mug-baseline.md)

## 更新规则

1. 每次运行使用 `YYYYMMDDTHHMMSS+0800` 时间戳。
2. 同时记录 Git commit、求解器版本、材料资产版本、网格设置、工艺边界和原始输出归档位置。
3. 结果必须区分材料误差、网格误差、边界/工艺误差和求解器误差；没有实测数据时不得写成“验证通过”。
4. 原始日志可以放在被 `.gitignore` 排除的 `report/`，正文只引用摘要和校验哈希。
